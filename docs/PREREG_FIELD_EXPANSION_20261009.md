### 3.2 P1 —— 零求解：取回 400 件 pod20 快照

**规模**：`400 快照 × 1 频点（20 MHz）= 400 次已完成的扫描例`；**新增求解次数 = 0**。

```
数据量      = 632,468,318 B                                    [实测: find -printf %s 求和]
下行时间    = 632,468,318 B ÷ 0.776 MB/s ≈ 632.5 MB ÷ 0.776 ≈ 815 s ≈ 13.6 min
            （保守取 0.5 MB/s ⇒ 1,265 s ≈ 21 min）
插值时间    = 400 × 10.04 s/快照 ≈ 4,016 s ≈ 66.9 min          [本机 CPU，零 COMSOL]
落盘        = 632.5 MB(原始) + 400×(1373×16 B) ≈ 632.5 + 8.8 = 641.3 MB
            ÷ C: 剩余 186.8 GB ⇒ 占 0.34%
COMSOL 预算 = 0 核时
```

**分块**：以 **N1 层为块**（5 块：N1=1/2/3/5/6，每块 80 件 ≈ 110–135 MB）。
每块一个 `.done` 标记（内容 = 块号 / 文件数 / 字节和 / 逐文件 sha256 / 起止远端钟）。
