## 2. 我的判断：裁定成立，而且数据支持它

我原本担心的"可能是不同结构"，现在**可以排除**，依据是一条新做的检验
（`model_equivalence_report.md` §4.1）：**逐频点比值是否恒定**。

两批唯一的参数重合组合是 **(x=0.1, N_w_te1=1, N_w_te2=9)**，在 7 个公共频点上作比：

| f (MHz) | 比 A/B `\|V_center\|` | 比 A/B `Vave` |
|---|---|---|
| 5.0 | 16.178 | 0.9438 |
| 10.0 | 16.207 | 0.9441 |
| 15.0 | 16.254 | 0.9444 |
| 20.0 | 16.321 | 0.9446 |
| 25.0 | 16.407 | 0.9447 |
| 30.0 | 16.512 | 0.9451 |
| 35.0 | 16.636 | 0.9459 |
| **散布** | **2.8%**（单调微漂移） | **0.2%** |

**为什么这条检验是决定性的**：

* 如果两批是**不同结构**，比值会**随频率变化**（各阶谐振的位置和幅度不同，峰位会错开）；
* 实测两批曲线**形状几乎完全一致**（都从 5 MHz 起单调上升、无峰位错动），
  各量只差一个**近常数**因子 ⇒ **与"同一结构 + 不同测点/归一化"一致，与"不同结构"不一致**。

**并且它顺便否掉了"只是激励电压不同"这个猜想**：若是单一激励差 λ，则**所有**线性量应同比缩放；
但两个量的常数**互不相同**（`V_center` 16.36 倍 vs `Vave` 1.0585 倍）
⇒ 差异是**逐列的测点/归一化定义**造成的，不是全局缩放。

**残留待解释项（如实列出，不掩盖）**：`|V_center|` 的比值有 **2.8% 的单调漂移**（16.178→16.636）。
若测点与归一化完全一致，该漂移应为 0 ⇒ 说明测点**位置略有不同**或存在次级效应。
**这一项要等 B 的测点定义才能定案**，我不猜。

### 3.2 没有改变（**这些仍然有效，且不能被裁定绕过**）

1. **`source_type` 不得混同**：`simulation` / `analytic` / `experiment` / `literature` / `ai_solver`
   仍各自独立。"同一模型"**不**意味着"同一来源类型"。
2. **来源列（profile）不同**：数据 B 只有 7 个频点、**无声压**、缺 `N_w_te1=7`。
   这是**覆盖/分辨率**限制，与"结构是否相同"无关：
   * B **不能**参与带宽/Q 与一阶峰分析（7 点 / 5 MHz 步长撑不起）；
   * B **不能**参与任何声压类指标；
   * **不得**用 `Ptot`/`Vave` 伪造声压（codex §9，采纳）。
3. **无 L1 网格收敛 ⇒ 不得给工程绝对值**。裁定与网格无关。
4. **无场数据 ⇒ 一阶峰不得宣称"振型已验证"**，只能 `provisional_first_mode`。
5. **数值仍必须可溯源**：每个数字要能指回 `run_id`/`sample_id`/`feedback_id`。
6. **人保留放行权**：模型状态晋升、报告放行仍由人做。

## 4. 核心新设计：**列级可合并矩阵**

"能不能合并"不该是一个全局的 yes/no，而应**逐列**判定。
判定依据只有一条：**该列在两批中的定义是否同一**（同点/同面/同表达式/同单位）。

### 4.1 输入轴（可合并）

| 列 | 数据 A | 数据 B | 判定 | 依据 |
|---|---|---|---|---|
| `x_scale` | 0.1–1.0（10 值） | 0.1–1.0（10 值） | ✅ **可统一** | 同名同义 + 用户裁定 + 形状检验一致 |
| `N_w_te1` | 1–7 | 1,2,3,4,5,6,**8**（缺 7） | ✅ **可统一为同一列** | 覆盖不全 ≠ 定义不同；缺失记 `NULL`，不插值 |
| `N_w_te2` | {3,4,6,7,8,9}（被扫描） | **常量 9**（不在表内） | 🟡 **可统一为列**（B 全填 9） | **需数据侧确认 B 的 `N_w_te2` 真值**（现依据是用户旧反馈"N_w_te2=9 保持不改"） |
| `freq_Hz` | 61 点 / 0.5 MHz | 7 点 / 5 MHz | ✅ **同一物理量，可统一为列** | 但**分析视图按分辨率分流**（见 §5） |
| `Vdiff`（驱动电压） | **未导出** | **未导出** | ❌ **两批都缺** | ⇒ 灵敏度类指标全部无法算 |

### 4.2 输出轴（**逐列**，当前唯一障碍）

| 输出列 | 数据 A | 数据 B | 判定 | 实测依据 |
|---|---|---|---|---|
| 复声压 / `spl_dB` @(0,0,−1e-5) | ✅ 有（含精确坐标） | ❌ 无 | ⛔ **只有 A 能用** | B 无声压 |
| 膜中心速度 | `Zdisplacement` @**(0,0,+1e-8)** | `V_center`（**测点未记录**） | ❌ **暂不可并** | 比值 **16.36**（散布 2.8%）⇒ 测点/归一化不同，**待 B 提供测点** |
| 面平均速度 | `Table_11` 体积速度 ÷ 自带面积 | `Vave`（**取样面未记录**） | 🟡 **最接近可并** | 比值 **0.9447**（散布 **0.2%**）⇒ 定义极可能相同，差 5.5% 待确认面积口径 |
| 声功率 | `p·conj(v)`：**复、有符号、实部可为负** | `Ptot`：**实、正** | ❌ **定义不同，不可并** | 20 MHz 处 A 实部 −1.1728e-10 W vs B +6.8482e-11 W |
| 总声压（力） | `Table_10` `总声压 (N)` | ❌ 无 | ⛔ 只有 A | — |
| 位移/应力/面积 | `Table_11`、`Zdisplacement` | ❌ 无 | ⛔ 只有 A | — |
| 电学阻抗 | ❌ **无** | ✅ `Zin1_R/X`、`Zin2_R/X` | ⛔ **只有 B** | ⇒ **A 的一阶峰无法用阻抗证据** |
| 振型 / 场 | ❌ 无（标量导出） | ❌ 无 | ⛔ 两批都无 | — |

### 4.3 由此得到的合并形态

**能立刻合并的是"骨架"，不是"数值"**：

```
统一长表（骨架） = (base_model_id, configuration_id, source_file, run_id,
                    x_scale, N_w_te1, N_w_te2, freq_Hz)          ← 输入轴，可立即统一
统一长表（值）   = 一行一列地挂上去：已确认定义相同的列才填值，其余留空并记原因
```

**关键点**：合并后的表必然是**稀疏长表**（不是无缝拼接）。
具体地：声压类**只有 A 有**、阻抗**只有 B 有**、`V_center` 暂不并、`Vave` 待确认、
功率类**定义不同不可并**。任何"把两批数据拼成一张稠密表"的做法都会**制造虚假数据**。

## 5. 分析视图按"分辨率与列可用性"分流（不按族分流）

| 视图 | 数据范围 | 可用列 | 用于 |
|---|---|---|---|
| `first_mode_dataset` | **仅 A**（61 点分辨率） | 声压 + 机械 + 面积 | 一阶峰位置/带宽/Q（B 的 7 点不够） |
| `target_20MHz_dataset` | **A + B**（20 MHz 是 B 的原始采样点） | 各自**已确认可用**的列 | 20 MHz 处的性能对比；**声压类只来自 A** |
| `pressure_dataset` | **仅 A** | 复声压 | 声压幅值/灵敏度（灵敏度仍缺 `Vdiff`） |
| `impedance_dataset` | **仅 B** | `Zin1/Zin2` | 电学谐振特征（**A 无此列**） |
| `repeatability_check` | **A ∩ B = {(0.1,1,9)}** | `Vave`、`V_center` | **批间一致性/可重复性**——这是"同源裁定"带来的**新能力** |

**`repeatability_check` 的用法**：同一结构、同一参数、两次独立扫描（扫描设置不同）
⇒ 是一个天然的**跨批重复性样本**。它现在的价值不是"多一个数据点"，
而是**给"列定义是否统一"提供了一个定量尺子**（比值是否恒定、漂移多大）。
若以后有更多重叠组合，这套检验可以直接升级为**批间系统偏差的标定**。
