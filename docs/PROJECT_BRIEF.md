## 1. 一句话目标

基于 **DeepSeek Harness**（一个 agent 框架）构建一个 **MEMS/PMUT 仿真自动化平台**：
平台自主驱动 **COMSOL** 求解 → 用求解数据与解析解扩充数据 → 训练 AI 模型 →
**最终在不调用 COMSOL 的前提下给出场级解**，并用 COMSOL 反过来验证；
模型可通过**实验数据、文献数据、人的反馈**持续增强。

## 5. 拟采用的技术方案

### 5.1 分层架构

```
L4 交互与增强层：DSH 智能体（人 ↔ 技能库 ↔ MCP 工具 ↔ 报告与门禁）
L3 模型层：① 代理层（标量/曲线，用于快速筛选）② AI 求解器（场级，免 COMSOL）
L2 数据工厂：解析解(F0) → 降阶1D(F1) → COMSOL 2D(F2) → COMSOL 3D(F3)，多保真
L1 仿真执行：队列 + 单实例串行调度 + 失败诊断 + 溯源（COMSOL 作为教师/验证器/兜底）
L0 数据与溯源：DuckDB + Parquet + 产物哈希 + 证据引用
```

### 5.2 自主寻优闭环（对应 R7）

人写一份**任务合同**（参数范围、目标、约束、预算、停止条件、结构变体清单、自动化级别），
平台随后自主循环：**选点 → 跑 COMSOL → 抽取目标数据 → 更新代理模型 → 采集函数选下一批 → 直到收敛**。
单目标用 EI，多目标用 qEHVI（输出 Pareto 前沿）。目标数据为**标量工程量**（f_r、Q、k_eff² 等，由谱线抽取），
谱线与场保留用于报告与残差检查。求解**单实例串行**（license/内存约束），批大小 20–24，前 2 轮逐轮批准。

### 5.3 场级免求解器（对应 R5，**一个月内的关键目标**）

| 路径 | 前提 | 样本需求 | 周期 |
|---|---|---|---|
| **降阶 POD/ROM（首选）** | 固定拓扑 + 1–2 个参数 | 30–60 个场快照 | **约 4 周** |
| 深度学习算子 FNO/DeepONet/GNO（升级） | 参数多、拓扑变化 | 数百–数千快照 | 再 3–4 周 |

POD 流程：`场快照 → 减均值 → POD 基(能量≥99.9%) → 基系数对参数回归(GP/Kriging) → 场 = 均值 + Σaᵢ(θ)φᵢ(x) → 留出场算相对 L2 → 误差界 → 物理一致性自校验 → 放行`

**关键前提 P1（已完成实测验证）**：POD 要求所有快照落在**同一套固定点集**上，而用户要改**几何尺寸**→网格会变。
实测结论（用本机一个只读的 2D 声学腔体小模型，非用户生产模型）：

| 项 | 实测 |
|---|---|
| 固定公共点集 | 31×23 = **713 点** |
| 基线 | 求解 0.8 s；网格节点 35724 → 插值到公共点集 713 点，0 NaN |
| 材料参数变化 | **快照等长 = True**，相对 L2 = 0.333 |
| **几何参数变化**（重建几何+网格） | **快照等长 = True**，域外 NaN = 92，相对 L2 = 0.313 |
| 结论 | **可行**；域外点需**掩膜**；实现走 **Python 侧插值**（不依赖 COMSOL 的 Grid 导出） |

被实测否决的三条路线：Grid 数据集+Eval（Eval 拒绝 Grid 数据集）、插值数据集（API 上下文无法创建）、
`Export(location=grid)`（网格定义不生效，导出 0 节点）。

### 5.4 验证与放行门禁

- **代理层**：L0 解析基准 → L1 网格收敛 → L2 守恒 → L3 交叉模型 → L4 仿真留出集 → L5 实验对标
- **AI 求解器**：S0 极限一致性 → S1 场级相对 L2 → S2 工程量误差 → **S3 物理一致性（守恒/边界/对称）** → S4 网格无关性 → S5 误差界校准
- **放行门禁**：`draft → physics_consistent → solver_certified → approved_solver`（**人工签字**）；运行时每次出解必须附**场级误差界 + 验证等级 + 适用范围判定**；**超范围拒答并回退 COMSOL**
- **两道硬门禁**：几何变更后必做**选择集完整性检查**（几何变了边界编号可能变、物理场会静默绑错，求解仍"成功"但结果错）与**网格依赖假最优检查**（扫描期网格按特征尺寸归一化重生，收敛后换 2–3 套细网格复算）

### 5.5 增强闭环（对应 R6）

- **实验**：用户**暂无实验数据** → 先建接入接口 + 模拟实验（含噪声与系统偏差）闭环
- **文献**：LLM 抽取 + **强制原文摘录与页码定位**（没有摘录不算证据）+ 多源一致性校验
- **人反馈**：修正值 / 偏好对 / 驳回意见三路消费；append-only 事件流
- 可持续增强的机制：数据入库 → 漂移/OOD 检测 → 再训练触发 → 阴影评估 → **人工放行** → 注册表

## 7. 已识别的风险与边界（诚实声明）

1. **不是通用替代**：AI 求解器只在**已声明范围**（固定拓扑、限定参数范围、指定研究类型）内可信；
   未见拓扑、强非线性/接触/失稳、强多物理耦合、极高局部保真度的问题**必须回退 COMSOL**。
2. **"像样但物理错误"的解**比报错更危险 → S3 物理一致性设为硬门禁。
3. **数据泄漏**：训练/测试集若含同族几何会系统性高估精度 → 按几何族整族切分。
4. **目标口径漂移**：f_r/k_eff²/Q 的定义差异常达几个百分点，**比整个优化的收益还大** → 口径版本化。
5. **中文路径 + JVM 冲突**（已实测并解决）：从中文路径启动 JPype 会报 `UnsatisfiedLinkError` → 需经 ASCII 交汇点启动。
6. **单机 6 GB 显存**：域级深度算子可能受限 → 故选降阶优先（CPU 分钟级）。
7. **用户模型尚未到位**：所有器件物理结论在模型接入前不做。

## 8. 评审问题清单（请逐条给意见）

1. **一个月交付「场级免求解器 + 自主寻优」是否现实？** 4 周排期有无致命遗漏（尤其 W1 依赖用户模型与口径确认）？
2. **POD/ROM 在"几何尺寸变化"下的可靠性**：公共点集 + 掩膜 + Python 插值的做法有无已知失败模式？
   插值误差会不会掩盖真实物理差异？是否应改为"同一网格拓扑 + 参数化变形"？
3. **场级误差指标是否合适**：相对 L2 ≤5%（关键区 2%）对 PMUT 是否太松/太紧？是否应改用**能量范数**或
   **关键工程量（模态频率、机电耦合系数、辐射声压）**作为主指标？
4. **验证充分性**：仅用 COMSOL 留出集验证"免求解器"是否足够？还需要哪些独立验证
   （解析解、守恒量、网格无关性、跨研究类型的迁移）？留出集应如何设计才算真正独立？
5. **样本量**：1–2 个参数的降阶模型，30–60 个快照是否够？如何判定"够了"（基能量占比？留出误差饱和？）
6. **闭环策略取舍**：单点 <5 min、预算 200–500 点的情况下，**COMSOL 在环贝叶斯优化**与
   **先用 AI 求解器大规模预筛再抽验**，哪种总成本/收益更优？有没有更好的采样策略？
7. **目标口径工程化**：f_r（阻抗峰/导纳峰/相位过零）、k_eff²、Q 的定义如何标准化，才能既贴文献又可比？
8. **物理一致性检查器**：S3 应包含哪些具体检查（守恒残差、边界条件残差、对称性、极限一致性）？
   阈值怎么定才不失真？
9. **多人使用与"工作模式"架构**：把平台做成一个 agent preset + MCP 工具集，是否会在并发、
   权限、审批流、数据隔离上留下结构性隐患？应从第一天预留什么？
10. **论文可用性**：这类"平台 + AI 求解器"的工作要发表，通常需要哪些**对照实验与消融**
    （vs 纯代理模型、vs 纯 COMSOL、样本效率曲线、误差界覆盖率等）？
11. **有没有更简单/更稳的替代路线**（例如先只做 2D 降阶、或先只做工程量级而非场级）能在同样时间内拿到更强结论？
12. **遗漏点**：上述需求与方案有什么明显缺口或过度设计？
