## 1. 目标与成功标准

### 1.1 器件层目标（来自《PMUT 模型研究说明》）

| 项 | 目标值 |
|---|---|
| 应用 | IVUS 血管内超声 |
| 中心频率 | 约 **20 MHz** |
| 带宽 | 约 **100% 的 −6 dB 带宽**（宽带平台型，而非单尖锐共振） |
| 结构路线 | 椭圆薄膜 + 双电极 + 多模态/反向驱动形成平台 |
| 阵列 | 一维阵列，pitch ≈ 100 µm，elevation ≈ 3 mm（**单元优化完成后再做**） |

### 1.2 平台层目标（`WORKING_PLAN.md` §7 的 P0–P7，本设备是其首个真实载体）

| 阶段 | 目标 | 本项目对应里程碑 |
|---|---|---|
| P0 环境打通 | ✅（本机已完成） | M0 |
| P1 资产整合 | ✅（迁移完成） | M0 |
| P2 仿真内核 | 可靠求解 + **参数/几何可自动化审计** + 选择集完整性检查 | M1、M3 |
| P3 数据工厂 | 解析 + 多保真 DOE | M3、M4 |
| P4 代理模型 | 带 UQ 的可用代理（留出集相对误差 ≤3%、90% 区间覆盖 85–95%） | M4 |
| P4.5 AI 求解器 | 场级免求解器（留出场级相对 L2 ≤5%、关键区 ≤2%、S3 通过、零 COMSOL 出解） | M5 |
| P5 增强闭环 | 文献/实验/人反馈三源接入 | M6 |

| P7 平台化 | 多器件模板、复现包、巡检 | 持续 |

### 1.3 不可含糊的验收底线

- 报告里每个数字都要能指回 `run_id` / `evidence_id` / `experiment_id` / `feedback_id`；
- 未过硬阈值的模型**只允许谈趋势**；
- AI 解必须带误差界 + S 级验证 + 适用域判定，超范围**拒答并回退 COMSOL**；
- 单元模型的结论**不得**用于宣称阵列性能。

## 3. 门禁与红线（每个任务都必须遵守）

| # | 约束 | 落地方式 |
|---|---|---|
| G1 | **单实例串行求解**，禁止并行扇出 | 队列 + 文件锁；长任务异步 + 轮询 |
| G2 | 改参只作用于**副本**；原件只读并记 SHA256 | `stage_model` + `set_parameters` 白名单写入 + 回读 |
| G3 | **几何变更后必过两道硬门禁**：① 选择集完整性 ② 网格依赖假最优 | 不通过即**作废**该点（不得降权保留） |
| G4 | 来源永不混同；训练/统计必须声明来源与权重 | `source_type` + `dataset.report.source_counts` |
| G5 | 没有证据不出数字；缺失写 `null` 并注明原因 | `uncertainty` / `quality` 字段 |
| G6 | −6 dB 的**评价对象与观察位置必须先钉死** | 见任务 T4；未定前不得报"带宽" |
| G7 | 预算（点数 + 机时）不可省；每轮报告卡 | 见 §6、§9 |
| G8 | COMSOL 步骤需**放宽的文件策略**；mphserver 默认不常驻 | `AGENTS.md` §3；脚本自管服务端 |
