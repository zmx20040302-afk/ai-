### 5.3 A6 三轮代理模型调试（**三轮全部负结果**）

> 三轮都是**先预注册（写在看指标之前）、后登记（append-only `prereg_registry.json` seq 1–4）**，
> 全部切分为**整族/整层**（禁止单点留出），从未针对留出回调超参或阈值。

**统一判定带**：标量 `pass` = max 相对误差 ≤ **3%**，`partial` ≤ **10%**；频谱 relL2 `pass` ≤ **5%**，`partial` ≤ **10%**；
且**必须同时优于全部基线**（含最近邻 B3），否则记 `not_better_than_baseline` 并降为 `fail`。

**统一目标定义**：`spl_20MHz_dB`(dB, 原空间)、`p_abs_20MHz_Pa`(log10)、`spl_max_dB`(原空间, 排除端点峰)、

**切分**：`S1` = 跨族（train `N2∈{3,4,6}` 92 点 → test `N2∈{7,8}` 130 点）；

折下限：训练 ≥20 且留出 ≥5，否则跳过并记原因。

**关键诊断（本轮真正的产出）**：
1. **目标本身有规律**——族内加性 `(x, N1)` 模型能解释 **83%–99.8%** 方差：

|---|---|---|---|---|

2. **`f_peak` 是分支跳变目标**：每族取值只落在 **9–19 个离散档位**、范围 5.5–35 MHz，

3. **S1 里混入了 N1 外推**：`disp_at_peak_m` 最差的 5 个点**全部**是 `N28` 的 `N1=7`，
   而训练族 N1 最大只到 **5** ⇒ 预测大了 **20–25 倍**。这部分失败应归因于**训练集覆盖不足**，不是"跨族不可学"。
4. **动态范围不是主因**：`p_abs` 1.8e3×、`disp` 256×、`f_peak` 6.4×、`BW` 7.5×、`Q` 4.4×；
   已按预注册在对数空间处理，失败量级不变 ⇒ **结构问题，不是尺度问题**。

>    ⇒ 两个 B3 数字略有差异（频谱 **11.3% vs 10.7%**）。这不是"结果变了"，是**两个不同基线**，如实并列。
