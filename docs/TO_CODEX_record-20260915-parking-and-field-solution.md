```text
① 用 COMSOL API 在网格节点上取坐标：evaluate("x") / evaluate("y") / evaluate("z")
② 同一批节点上取场值：evaluate(<field expression>)
③ 在 **Python 侧**用 scipy.griddata 插值到**固定公共点集**（几何变化后快照仍等长）
```
