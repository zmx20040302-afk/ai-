## 1. 冻结任务

- 三个设计参数：`x_scale`、`N_w_te1`、`N_w_te2`。
- 每个设计先定位并核验自己的第一阶模态，不使用统一固定频率替代。
- 标量目标：全局坐标 `(0,0,-10 µm)` 的 `|acpr.p_t|`。
- 场目标：同一频率下完整复声压场 `p_total_Pa` 的实部和虚部。
- 生产 `.mph` 只读；参数只写入副本；COMSOL 串行；最终放行权在人。

## 2. 为什么目标不再是插值器

`N_w_te1/N_w_te2` 会改变离散结构，谐振模态还会切换。把不同结构或不同模态放进一个全局
低维坐标后直接插值，现有实验尚未实现可靠的跨结构迁移。现有固定
20 MHz 场插值只作为基线和失败对照，不再承担目标求解器角色。

算子路线也不等于“换模型后完全不用 COMSOL”。正确口径是：复用跨模型学到的算子权重，
以少量新模型校准点和独立留出点为目标。实际所需点数必须实验测定；若门禁不通过则拒答。
算子仍然是学习到的近似映射，分布内泛化也可被称为统计意义的插值。用户要求禁止的是直接
用邻近参数点插值生成目标场解或伪造训练真值，不是声称神经算子能免除分布限制。

## 3. 推荐架构

采用两段式、可拒答的模型：

1. **频率预测与模态路由器**：训练/验证时用真实扫频、结构响应和模态连续性确定标签。
   日常推理从设计描述预测 `f1`、模态身份和不确定度，不要求每个查询先做 COMSOL 扫频；
   仅在模态不确定、超范围或验证候选时补算。真实首峰只是暂定标签，需验证其物理模态身份。
2. **几何条件神经算子**：优先使用网格图/几何图编码器，输入网格拓扑、坐标、材料场、边界
   条件的标签与数值、激励幅值/相位、损耗、三个参数和真实或预测的一阶频率；输出查询坐标上的
   `Re(p_total)`、`Im(p_total)`。使用坐标查询头直接在 `(0,0,-10 µm)` 预测，其误差仍需独立验证。
   训练与端到端测试必须分别报告真实频率输入误差和预测频率输入误差，覆盖谐振频偏的放大效应。

当前建议先评估 GINO 类图算子编码/解码与潜在网格算子，适配不规则采样和几何变化。
这是架构候选，尚无 PMUT 实测证明优于其他方法。公共网格映射会引入离散化误差，必须测量，
不能称“无损”。DeepONet 可作为坐标查询基线，但其几何
分支必须接收几何/材料/边界条件表示，不能只接收三个标量参数。

## 4. 数据单元与切分

一个样本必须包含：模型哈希、网格/几何表示、材料与边界条件、三参数、一阶频率与模态身份、
复声压场、精确观测点标量、网格收敛证据和求解日志。切分以“完整几何/模型”为组进行，不能把
同一模型的相邻参数点同时放进训练和测试，从而伪装成跨模型泛化。

依次建立三种测试：

- 同一模型内未见参数；
- 未见离散结构分支；
- 未见模型几何（DAC 主测试）。

## 5. 主动补点顺序

1. `2430` 个候选网格点和 `N_w_te2=9` 的 `648` 个缺口是覆盖统计，不是必须执行的 FEM 任务数。
   先选少量离散分支锚点与预先锁定的留出点，其中包含 N2=9；对未找到首峰的设计检查低频窗口；
2. 在每个离散分支选少量锚点导出一阶复场，训练首版算子；
3. 按算子不确定度、模态路由不确定度和物理残差联合选点；
4. 将用于主动选点的开发集与最终盲测集分开；最终盲测结果不得用于本轮选点或调参，
   若使用失败结果调整下一轮模型，须重新保留独立测试集；
5. 仅在预注册场误差、关键区域误差、观测点误差和模态身份门禁全部通过后，允许进入
   “预测候选 → 修改模型副本 → COMSOL 独立复算”的闭环。

## 6. DAC 论文核心命题

论文不应主张“一个更大的网络替代 COMSOL”，而应验证：

> 模态感知、几何条件的神经算子，加上主动 COMSOL 采样与可审计拒答，能否在未见 PMUT 模型上
> 用显著少于全量扫描的真实求解达到可验证的一阶复声压场精度。

必须报告算子对插值、POD、DeepONet/FNO 基线的对比；同时报告新模型所需 COMSOL 校准点数、
独立留出误差、失败/拒答率、端到端墙钟和模型修改后复算一致性。任何“减少计算量”的数字都要
来自真实实验，当前阶段不预填结论。
