## 2. 灵敏度的正式定义

当前模型的实际电极条件为：

- 内电极：`−1 V`；
- 外电极：`0 V`；
- 实际差分驱动电压：`ΔV = 1 V`。

因此：

```text
linear_response_per_V = linear_response / ΔV
SPL_per_V = SPL_original - 20*log10(ΔV)
```

在当前 `ΔV=1 V` 的条件下：

```text
linear_response_per_V = linear_response
SPL_per_V = SPL_original
```

数值虽然不变，仍必须在字段和报告中保存以下信息：

- 原始响应；
- `V_inner=-1 V`；
- `V_outer=0 V`；
- `ΔV=1 V`；
- 归一化公式；
- 单位电压响应。

当前模型不得描述为“外电极 `+1 V`、内电极 `−1 V` 的 2 V 反相驱动”。

## 3. 三项研究目标的判定口径

### 3.1 振幅

主要使用：

- 中心位移幅值 `abs(w)`；
- 结构速度幅值；
- 声压幅值 `abs(acpr.p_t)`；
- SPL。

正式排名时必须说明采用的空间位置、频率和电压归一化方式。

### 3.2 带宽

正式排名指标：

- 一阶谐振峰左右 `−3 dB` 截止频率；
- 绝对带宽 `BW = f_hi − f_lo`；
- 带内平坦度。

Q 因子和阻尼比仅作为合格门槛，不作为主要排名指标。若一阶峰或任一侧截止频率不闭合，则正式的 `BW/Q/阻尼` 标签必须为空。

单边拟合外推可以保留为诊断信息，但必须标记：

```text
extrapolated = true
ranking_eligible = false
```

### 3.3 灵敏度

灵敏度使用单位差分驱动电压下的：

- 中心位移；
- 结构速度；
- 声压；
- SPL。

当前 `ΔV=1 V`，归一化前后数值相同，但不能省略电极和电压元数据。

## 4. 一阶峰指标表的导出要求

同意从已有解重新导出并整理一张“一组合一行”的指标表，不重新运行求解器。

最低字段要求：

```text
x_scale
N_w_te1
N_w_te2
f_peak_Hz
peak_SPL_dB
peak_displacement_m
f_lo_3dB_Hz
f_hi_3dB_Hz
bandwidth_Hz
Q_factor
damping_ratio
peak_closed
bandwidth_closed
method
extrapolated
ranking_eligible
source_model
source_dataset
```

不得依靠原始 marker 表的隐式行序推断参数归属。若 COMSOL marker 表无法稳定携带参数列，应直接从带参数列的完整频谱表逐组合计算上述指标。

## 5. 无峰与边界组合

### 5.1 170 个无一阶峰组合

先按以下参数统计分布：

- `x_scale`；
- `N_w_te1`；
- `N_w_te2`；
- 扫描起点和终点处的频谱斜率；
- 是否集中在参数边界。

在统计完成前，不得简单解释为“性能差”。

- 若属于零散、非关键组合：排除一阶峰排名，但保留频谱预测能力；
- 若集中在低频或高频边界附近：只对该参数区域进行局部扩扫；
- 不默认对全部 170 组重新求解 1–60 MHz。

### 5.2 右侧 −3 dB 截止超过 50 MHz

严格执行 fail-closed：

- `bandwidth_closed=false`；
- 正式 `BW/Q/damping_ratio` 为空；
- 不参与带宽排名；
- 对重要候选设计单独扩展扫频上限。

## 6. 代理模型能力声明

代理模型只有同时满足以下条件，才允许作有限范围内的能力声明：

1. 相对于最近邻基线具有配对优势；
2. 达到预注册的绝对误差门槛；
3. 明确报告可答域覆盖率和拒答率；
4. 报告最差组合，不能只报告 median；
5. OOD 或拒答域内不输出预测数字。

`M11` 保留作研究参考，但在无法完成独立校准时：

```text
capability_claim_allowed = false
```

## 7. 跨批一致性和异常点

跨批一致性报告必须同时给出：

- 20 MHz 标量误差；
- 频谱误差的 median、p90 和 max；
- 最差组合及其参数；
- 逐组合误差排名；
- 异常点是否被隔离。

批 A 的异常角点继续隔离，同时进行独立复算。在取得以下证据前，不判断哪一批错误：

- `mesh_fingerprint`；
- 解索引和参数映射；
- 两侧角点独立复算结果；
- 几何域、网格节点和自由度对照。

历史冻结产物不修改；新的归因通过追加记录发布。

## 8. te2_9 到达后的执行顺序

```text
1. 检查角点 (x_scale=0.2, N_w_te1=1, N_w_te2=9)
2. 执行 L-N2ex(9) 主折
3. 执行标尺折和校准折
4. 把 N2=9 作为两步外推边界测试
```

M11 在缺少足够训练层时仍标记为不可校准，不得因 N2=9 到达而自动升级能力声明。

## 9. 场模型、S1/S3/S5 与措辞门禁

当前 te2_8 场快照导出任务继续运行。COMSOL 侧工作顺序为：

```text
场快照导出完成
  → mesh_fingerprint
  → PMUT 最小 L1 网格收敛
```

场数据到达只代表可以开始 POD-ROM，不等于已经成为可替代 COMSOL 的求解器。

在 S1、S3、S5 全部通过前，禁止使用以下表述：

- “AI 求解器”；
- “免 COMSOL 出解”；
- “等价于 COMSOL”；
- “可以给出工程绝对值”。

允许使用的表述是：

> POD-ROM 研究原型，当前用于离线场重建、误差评估和适用域验证，尚未通过求解器级门禁。

## 10. 网页控制台裁定

### 10.1 新增图形

增加：

1. 振幅—带宽—灵敏度 Pareto 图；
2. 参数敏感性热力图。

优先实现 Pareto 图。不得把没有闭合带宽的组合放入正式 Pareto 前沿。

### 10.2 交互和访问

- 点击侧栏“预测”只切换页面，不自动发起计算；
- 用户在预测页面内点击正式按钮才执行；
- 当前仅监听 `127.0.0.1`；
- 暂不开放局域网；
- 服务按需启动，不安装定时自愈。

- 一阶谐振峰识别；

与当前主线无关的 `pending_human`、旧冻结漂移和 LT0-E 暂不投入资源，但不得删除历史记录。
