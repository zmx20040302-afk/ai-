## 1. 它到底要什么（客观复述，不评价）

任务书要求把 PMUT 项目从「若干分散的通过结果」重组成一条**面向 DAC EDA6.5（Model order reduction techniques for analog/RF designs）**
的可投稿降阶求解器（ROM）证据链，其技术主张是「**物理门控的局部降阶模型库**」：

1. **先在 P0 把证据基础修好**：冻结唯一的全阶模型身份（FOM identity）、修正端口与功率定义（`Zin2≡Zin1`、`I02`、损耗/辐射）、
   重做 S3 物理一致性（换法向、独立比较电路电流与场积分到 <0.5%、把 Sound Hard 残差扩到试验基、解释 `P_rad/P_in>1`、阈值改从 spec 读并加自动测试）、
   按联合键 `(model_sha, topology, continuous_parameters, frequency, field_expression, mesh_id)` 审计**真实的独立样本数**；
2. **P1 形成最小可投稿闭环**：以 N1=4 / N1=7 为两个局部 ROM 基准族、扩一阶峰附近的多频**场与端口**数据、建端口级有理 ROM（投影/PRIMA/Krylov 或 Vector Fitting，查极点稳定与无源性）、
   重新预注册主 S5 协议、在最终 FOM 上重做预注册 S4、完成时间/内存/盈亏平衡（break-even）评测；
3. **P2 增强**：自适应采样、拓扑感知 ROM 库（未见拓扑默认 OOD 拒答并回退 COMSOL）、系统级接口（状态空间／SPICE／Verilog-A／Simulink）、强基线与消融；
4. **执行顺序**明确为「模型身份与端口冻结 → S3 修复＋样本审计 → 预注册 S4 → 复现两族 → 扩多频 → 联合建模 → 独立测试与新 S5 → 加速证据 → 拓扑库与回退 → 系统级与写作」，
   并声明「**不能把第 5 阶段放在第 1–3 阶段之前**」；
5. **门槛表**给出九行「最低门槛／理想目标」，并声明「加速比目标应根据实际测量调整，不能在实验前写成已达成事实」；
6. **给 DeepSeek Harness 的 10 条直接执行指令**与**五个优先产物**：`FOM_IDENTITY_AND_PORT_CONTRACT.md`、`S3_REPAIR_REPORT.md`、
   `INDEPENDENT_SAMPLE_AUDIT.tsv`、`MULTIFREQUENCY_ROM_PROTOCOL.md`、`EDA65_RELEASE_GATE.json`（「前三项未完成前，不启动大规模多频 COMSOL 追加计算」）。
