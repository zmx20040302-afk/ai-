### 1.3 参数效验（哪些参数真起作用）

run `audit-20260912T072644Z-fffb8987`（单频点 **10 MHz** 口径，Δ=+5%，14 个非几何参数）：

- **只有 `v0` 有效**：目标量相对变化 **5.000e-02**，与扰动幅度**完全相等** ⇒ 纯线性增益、无权衡 ⇒ 不宜作设计变量（应固定 1 V 归一化）。`[实测]`
- **13 个逐位 0.0**（不是"很小"）：`h_tox`、`h_box`、`h_handle`、`N_p_te1`、`V_te1`、`N_p_te2`、`V_te2`、`p_be1`、`V_be1`、`x_scale_2`、`c_air`、`f_min`、`f_max` ⇒ 求解器确定性、噪声地板为 0。`[实测]`
- **几何类 11 个**（改几何/网格规模）：`h_te`、`h_pzt`、`h_device`、`h_parylene`、`W_min`、`N_mem`、`N_w_te1`、`N_w_te2`、`x_scale`、**`c_water`**、**`fmax`**（后两者经 `lamda=c_water/fmax → 网格 hmax=lamda/5` 进几何）。`[实测]`
- **方法学局限**：零值参数（`N_p_te1=0`、`p_be1=0`、`V_be1=0`）的相对扰动是恒等变换 ⇒ **本方法无法判定**；单频点结论只在该频率成立。`[实测]`

## 2. 【本轮最紧要】新网格（9×9=81 组合）的几何自洽性预判

新扫描口径（据 Codex 指令）：`x_scale = 0.4:0.05:0.8`（9 档）× `N_w_te1 = 0:1:8`（9 档）= **81 组合**；若全成功且 7 频点 = **567 行**。

用 §1.5 第 2 条的公式（假设沿用当前 `W_min=4.2µm`、`N_mem=10`、`N_w_te2=9`）逐组合判定（计数互不重叠，合计 81）：

| 结果 | 组合数 | 说明 |
|---|---|---|
| **几何自洽**（无重叠 ∧ 内电极在膜内 ∧ N>0） | **40** | 可参与排名 |
| 内外电极**重叠**（含其中 25 个同时越出膜短轴） | **32** | 边界条件与设计意图不符 |
| ├─ 其中：内电极圆**越出膜半短轴** | （25） | 是"重叠"的子集：越膜必然先重叠 |
| └─ 仅重叠、未越膜 | （7） | |
| `N_w_te1=0`（内电极宽 0，几何可能退化） | **9** | 单列处理 |
| **合计存疑** | **41**（=32+9） | 见 D2 |

判定条件：
① 重叠 ⟺ `N_w_te1*W_min+1µm > N_w_te2*W_min*x_scale−1µm` ⟺（`N_w_te2=9` 时）**`N_w_te1 > 9*x_scale − 0.476`**
② 超膜 ⟺ `N_w_te1*W_min+1µm > R_mem*x_scale` ⟺ **`N_w_te1 > 10*x_scale − 0.238`**

| x_scale | 膜半短轴 µm | 外环内径 µm | 重叠起点 | 超膜起点 | **自洽 N 范围** |
|---|---|---|---|---|---|
| 0.40 | 16.80 | 14.12 | N≥4 | N≥4 | **1–3** |
| 0.45 | 18.90 | 16.01 | N≥4 | N≥5 | **1–3** |
| 0.50 | 21.00 | 17.90 | N≥5 | N≥5 | **1–4** |
| 0.55 | 23.10 | 19.79 | N≥5 | N≥6 | **1–4** |
| **0.60（文献基准）** | 25.20 | 21.68 | N≥5 | N≥6 | **1–4**（基准 (0.6, 4) ✅ 在自洽区） |
| 0.65 | 27.30 | 23.57 | N≥6 | N≥7 | **1–5** |
| 0.70 | 29.40 | 25.46 | N≥6 | N≥7 | **1–5** |
| 0.75 | 31.50 | 27.35 | N≥7 | N≥8 | **1–6** |
| 0.80 | 33.60 | 29.24 | N≥7 | N≥8 | **1–6** |

**为什么这决定数据能不能用**：若不加区分，数据很可能呈现"`N_w_te1` 越大响应越强"，而其中相当一部分实际是**内电极已铺满整膜甚至越出膜外**——此时它不是"双电极设计"，而是"单电极/退化电极"。这属于本项目定义的**假最优**，不能作为优化结论。

`[静态可复核]`：落档 `work/reports/modelio/new-grid-geometry-precheck.json`（逐 81 组合的 `overlap` / `exceeds_membrane` / `geometrically_clean`）。
`[待核实]`：上述假设用当前模型的公式与参数；**新批次 `.m` 到手后必须用它复核**（尤其 `N_w_te2` 是否仍是 9、电极选择集是否改过）。

> 另：`N_w_te1=0` 时 `N_w_te1*W_min=0`，几何特征可能退化为零宽矩形；而批处理节点设了 `model.batch('p1').set('err','on')`（**出错继续**）⇒ 失败点会被**静默跳过**。因此"实际行数 < 567"本身就是一条需要解释的数据质量事实（需要 Batch 日志才能归因）。
