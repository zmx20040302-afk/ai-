```text

all_assignment_locations

downstream_geometry_references
downstream_material_references
downstream_physics_references
```

规则：

- `.m` 文件同名参数以最后一次赋值为准；例如当前 `N_w_te2` 的有效值是末尾覆盖后的 9；

- 其余曾经“变化为 0”的参数一律标记 `unverified_or_inactive`，不得直接纳入下一轮扫描；
- 每个新增参数必须证明至少一个下游表达式真实引用它，并通过小扰动产生预期的几何、材料、边界或响应变化；
- 不得只比较最终求解量。几何参数先比较尺寸/面积/包围盒，材料参数比较求值后的材料属性，电路参数比较端口电压电流，网格参数比较网格统计。

## 3. M1：先做端口与 `Zin2` 取证

### 3.1 求解设置

使用母版的轻量副本，固定参数：

```text
x_scale = 0.6
N_w_te1 = 4
freq = 5[MHz], 20[MHz], 35[MHz]
drive_mode = circuit_terminal_1ohm_current_model
```

此步骤先沿用原网格口径，目的是确认电路和变量定义；不要同时修改驱动、网格和频率范围，否则无法判断差异来自哪里。

### 3.2 必须保存的原始量

每个频点必须保存复数实部和虚部，不能只保存幅值：

- 内电极实际复电位 `V_inner`；
- 外电极实际复电位 `V_outer`；
- `I01`、`I02` 复数值；
- `I01`、`I02` 对应的电路元件/端口标签；
- COMSOL 对每个电流变量规定的正方向；
- `V_outer - V_inner` 的复数值、幅值和相位；
- 当前 `Zin1`、`Zin2` 表达式原文、数值和单位；
- `term1`、`R1`、被停用的 `pot1` 的启用状态与选择对象。

不要先假设正确的第二端口公式。应从电压参考方向和电流正方向推导：

```text
Z = 端口参考电压 / 流入该端口正端的电流
```

如果 `I02` 的方向与端口电压参考相反，负号应来自明确的方向定义，而不是为了让曲线“看起来正常”而添加。

### 3.3 放行判据

`port_audit.csv/json` 和报告必须回答：

1. 两电极到底是同相、反相，还是一端近似浮置？
2. 实际幅值是否等于设置值，还是受 1 Ω 电路支路影响？
3. `I01` 与 `I02` 是否真属于不同端口？
4. 现有 `Zin2 = v0/I01` 是否只是错误重复？
5. 本轮是否能给出可审计的正确 `Zin2`？

处理规则：

- 驱动口径确认、`Zin2` 也确认：继续并输出两阻抗；
- 驱动口径确认、`Zin2` 仍不能可靠定符号：继续，但 `Zin2` 标为 `excluded_unverified_definition`，不得参与排名；
- 实际驱动与声明的 `circuit_terminal_1ohm_current_model` 不一致：停止，提交证据，等待决定是否修正驱动；不得静默改接线。

## 5. M3：先跑基准，不立即放开全部候选

### 5.1 基准哨兵

新网格先求以下 5 个频点：

```text
5, 15, 20, 35, 45 MHz
```

验收：

- 5/5 收敛；
- `Ptot >= 0`；
- `Vave`、`Ptot`、`Zin1`、`V_center` 均为有限值；
- 频率标签和数据行一一对应；

- 记录运行时、峰值内存和结果文件 SHA256。

若哨兵失败，不运行 81 点；先定位求解器、网格或表达式问题。

### 5.2 81 点采用 4 个串行 chunk

每个候选建立一个 parent run，下面包含 4 个 child run：

| chunk | 频率范围 | 点数 |
|---|---|---:|
| C1 | 5–15 MHz，步长 0.5 MHz | 21 |
| C2 | 15.5–25 MHz，步长 0.5 MHz | 20 |
| C3 | 25.5–35 MHz，步长 0.5 MHz | 20 |
| C4 | 35.5–45 MHz，步长 0.5 MHz | 20 |
| 合计 | 5–45 MHz | **81** |

规则：

- child run 串行执行，禁止并行占用许可证和内存；
- 每个 child 使用独立 server 生命周期，结束后检查端口；
- 每个 child 输出自己的 model/script/criteria/mesh 哈希；
- parent 聚合时验证频率唯一键为 81、重复 0、缺失 0；
- 一个 chunk 失败时只重跑该 chunk，不重跑已通过部分；
- 每个频点完成后及时写标量 checkpoint；不要等 20/21 点全部完成后才写唯一结果文件。

如果现有求解接口可以在同一 server 内逐频率安全写 checkpoint，也必须保留上述 parent/child 逻辑；不能用一个无法断点恢复的单一 81 点任务替代。

## 8. M6：7R 轴向声压不要扩大模型域，优先使用 `efc1`

### 8.1 正确理解

当前固定外半球半径约 100 µm，而报告提出的 7R 点为 294 µm。该点在当前有限元声学域外，所以：

- 不能直接在 `(x,y,z) = 膜中心 + 7R·轴向单位向量` 处求域内压力变量；
- 现有模型已经有 `efc1`，应优先使用 Exterior Field Calculation 生成的外场算子（常见默认名为 `pext`）在域外求复声压；
- COMSOL 官方说明 Exterior Field Calculation 可以利用包围声源的连续边界，在计算域外任意距离评价声压；因此不应为了一个 7R 点直接把全部 3D 流体域扩大到 294 µm。

参考：

- [COMSOL：Exterior Field Calculation](https://doc.comsol.com/6.3/doc/com.comsol.help.aco/aco_ug_pressure.05.027.html)
- [COMSOL：Evaluating the Acoustic Field in the Exterior](https://doc.comsol.com/6.3/doc/com.comsol.help.aco/aco_ug_pressure.05.141.html)

### 8.2 必须先验证的内容

1. `efc1` 选择的是连续、包围全部声源/散射体的正确边界；
2. 法向方向正确；若是外部辐射边界，确认 COMSOL 自动方向处理适用；若是内部边界，检查是否需要 Reverse normal direction；
3. 对称面设置与实际半/四分之一模型一致；
4. 膜中心的全局坐标和辐射轴方向已从几何中读取，而不是假定原点；
5. `R` 的定义已确认。只有物理膜半径确为固定 `R_mem = 42 µm` 时，才能固定写 `7R = 294 µm`；若候选会改变物理膜半径，则每个候选的观察点必须随 `R` 更新；
6. 保存 `pext` 的复数值，再计算幅值、相位和归一化响应。

建议表达形式为：

```text
r_obs = r_membrane_center + 7*R_physical*axis_unit_vector
p_7R_complex = pext(r_obs_x, r_obs_y, r_obs_z)
H_p_7R = abs(p_7R_complex) / abs(V_drive_reference)
```

变量标签不能凭经验写死，必须从模型中读取 `efc1` 实际配置的 exterior field variable name。

### 8.3 外场验证

在批量计算 7R 前，对基准的 5/20/35 MHz 做小样：

- `pext` 可正常返回有限复数；
- 轴向距离取若干点时，结果连续；
- 法向翻转检查不会暴露明显相位/幅值错误；
- 对称因子与全空间/半空间解释一致；
- 报告 7R 位于近场还是远场，不能因为叫“Exterior Field”就自动称为“远场”。

只有 `efc1` 无法通过验证时，才另立模型分支研究扩展流体域 + PML/Perfectly Matched Boundary；该分支不得覆盖当前 `Ptot` 证据链。

## 9. 结果解释边界

本轮最终可说：

- 单 PMUT 单元在当前电路驱动下的机械速度响应；
- 穿过固定外半球面的向外声功率；
- 经验证外场算子得到的 7R 轴向复声压/归一化声压。

本轮仍不能说：

- 阵列声功率、波束或阵列增益；
- 接收灵敏度；
- 往返脉冲回波带宽；
- 实验已验证的最终器件性能；
- 理想反相恒压驱动性能（除非另建并验证该驱动模型）。

粗扫 5 MHz 间隔结果只用于候选筛选；最终带宽由 0.5 MHz 精扫和明确的上下交点状态决定。任何到 45 MHz 仍未闭合的曲线必须标记 `upper_bound_not_found = true`，不能把 45 MHz 当成真实交点。
