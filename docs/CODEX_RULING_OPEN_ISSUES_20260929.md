## 0. 总裁定

当前最需要修正的不是代理模型，而是评价协议。立即执行以下五项裁定：

1. **停止使用 `p_abs_20MHz_Pa` 的普通相对误差作为放行指标。**
2. **停止在 dB 值上使用“相对百分比误差”和“残差小于 3%”的说法。**

## 1. 两项判定量的正式口径

### 1.1 20 MHz 声压目标

采用以下三级结构：

| 层级 | 指标 | 用途 |
|---|---|---|
| **主指标** | `abs_error_SPL20_dB = abs(SPL_pred − SPL_true)` | 排名、比较和放行 |
| 辅助指标 | `abs_error_p20_Pa = abs(abs(p_pred) − abs(p_true))` | 显示物理量绝对差 |
| 诊断指标 | `abs(log10(max(abs(p_pred),p_floor)) − log10(max(abs(p_true),p_floor)))` | 检查跨数量级误差 |

普通相对误差 `abs(Δ|p|)/|p|` 从主判定中撤下。它可以保留在诊断表中，但当
`|p_true| < p_floor` 时必须写成 `not_applicable`。`p_floor` 不应凭空指定为 1 Pa，建议在训练集内预注册为：

```text
p_floor = max(仪器/数值噪声下限, 训练集 |p| 的第 1 百分位)
```

不能使用测试集来选择 `p_floor`。

### 1.2 dB 指标的统一判定带

对逐点绝对 dB 误差，固定报告：`median / p90 / p99 / max / >0.5 dB 比例 / >1 dB 比例`。

本项目下一轮建议采用：

| 判定 | 条件 |
|---|---|
| **pass** | `median ≤ 0.05 dB`、`p90 ≤ 0.20 dB`、且 `|误差|>0.5 dB` 的比例 ≤5% |
| **partial** | `p90 ≤ 0.50 dB`、且 `|误差|>1 dB` 的比例 ≤5% |
| **fail** | 其余情况 |

`max` 不再单独决定全局 pass/fail，因为实测已经证明它会被极少数窄分支控制且随 h 非单调。
但 `max > 3 dB` 必须触发“局部热点未闭合”旗标，禁止宣称全域光滑或全域收敛。

据此，h=0.02 的中点结果应表述为：

> 全局主体已经接近稳定（median=0.013 dB、p90=0.17 dB），但 x≈0.20–0.26
> 仍存在局部尖锐分支（max=5.92 dB），因此“全局停止加密、热点局部继续加密”，而不是整批继续均匀加密。

不得把 dB 残差再除以 dB 真值，也不建议用“相对峰高百分比”替代，因为这会引入参考零点和峰定义的新歧义。

### 1.3 历史结果如何处理

- 四轮历史 JSON、报告和旧预注册保持不变。
- 新建 `metric_protocol_v2`，用保存的逐点预测重新计算新指标。
- 新报告并列展示 v1 与 v2；v1 只作历史追溯，不再用于下一轮放行。
- 这属于“评价协议修订”，不是对历史数据的偷偷重算。

## 2. “打赢最近邻”的新判据

只比较同一个测试点上的配对误差。对每个测试点定义：

```text
d_i = abs_error_model_i − abs_error_baseline_i
```

模型被判为优于最近邻，必须同时满足：

1. `median(d_i) < 0`；
2. 模型逐点胜率 `P(d_i<0) > 55%`；
3. 配对 bootstrap 的中位差 95% 置信区间上界 `< 0`，或预注册的一侧 Wilcoxon 检验 `p<0.05`；
4. `p90` 绝对 dB 误差至少改善 **0.10 dB**，避免“统计显著但工程上无意义”；
5. 模型的 `max` 不得比基线恶化超过 **0.5 dB**；否则标记为“主体更优但产生新灾难点”，不能称为完全胜出。

因此，第四轮“4.11% < 4.70%”只能保留为 **v1/max 口径下的暂定胜出**。
必须按上述配对规则重算后，才能声称 M7 真正打赢 B3。

### 2.1 频谱误差

停止把 `norm(SPL_pred)/norm(SPL_true)` 一类 **dB 空间相对 L2** 作为主指标；dB 的基准平移会改变分母，物理意义不稳。

新顺序为：

1. 主指标：逐频点 `|ΔSPL|` 的 `median/p90/p99/max`；
2. 辅助指标：`RMSE_dB`；
3. 若有复声压：复数声压的能量归一化 L2；
4. 若只有幅值：线性声压幅值的归一化 L2；
5. 可增加“峰附近窗口”和“20 MHz 附近窗口”，但窗口必须在训练前固定。

所有频点同权可作为“全带平均表现”；若工程目标是 20 MHz，则另报目标窗口，不能事后按误差大小改变权重。

## 3. 切分、跨批和模型公平性

### 3.1 `S-CB` 的身份

“A 的同参数 → C 的同参数”保留，但正式改名为：

```text
R-CB：跨批重复性/口径一致性检查
```

它不是泛化测试，不能用来证明代理模型会预测新参数。

真正的跨批泛化折应为：

- 训练：A 的粗网格；
- 测试：C 中不与 A 坐标重复的 x 加密点；
- 只保留位于同层已知 x 范围内部的插值点；
- 外推点单独建折，不与插值混合；
- 异常组合 `(0.2,1,7)` 在主表中标记 `quarantined`，同时给出含它和不含它的敏感性结果。

现有探索性 `A → C 新加密点` 正是正确方向，但它未预注册，所以只能作为探索证据。
下一轮把该折预注册后才能参与正式判定。

### 3.2 `S-D(h)` 是否偏袒 M7

结论是：**如果实际部署方式就是“固定 `(N2,N1)` 后沿 x 插值”，M7 的归纳偏置合理；但比较基线必须匹配同样信息条件。**

下一轮设置两条赛道：

| 赛道 | 用途 | 必须包含的基线 |
|---|---|---|
| 运行场景赛道 | 同层内沿 x 插值 | 同层最近邻 `B3-L`、同层线性 M7、PCHIP/局部样条 |
| 全局泛化赛道 | 跨 N1/N2 或新层预测 | 全局最近邻、全局回归/局部模型；M7 不适用时明确 N/A |

不能再让“同层 M7”只和“全局欧氏距离 B3”比较后得出普遍优越结论。

### 3.3 密度收益和 h=0.01

- 密度收益以 `median/p90/超阈值比例` 为主，`max` 单列作热点哨兵。
- 删除“用全 0.01 网格训练时误差一定不大于 4.11%”这句话。实测 max 非单调，无法推出该上界。
- 正确验证方式是 **h=0.01 网格的内部留一 x 检验**：每层删除一个内部 x，用两侧最近训练点预测；端点不参与插值评价。
- 如果训练集包含全部 0.01 x，沿 x 已没有未见内部点；此时真正要测的是新 N1/N2 层、制造偏差或新几何，而不是再报告训练坐标重构误差。

## 4. 35 MHz 与 50 MHz 的范围依赖量

建议执行“双视图”，不是二选一：

### 4.1 原生视图

- A 保留 5–35 MHz 原生指标；
- C 保留 5–50 MHz 原生指标；
- 用于各批内部描述，不跨批直接比较范围依赖量。

### 4.2 公共窗口视图

把 C 截取到 5–35 MHz，重新计算并新增带后缀的列，例如：

```text
f_peak_5_35_Hz
spl_max_5_35_dB
bandwidth_3dB_5_35_Hz
peak_at_range_edge_5_35
bandwidth_not_closed_5_35
```

原 5–50 MHz 列不得覆盖。跨批比较只使用公共窗口列，并且仅限：

- 峰不在公共窗口边界；
- 左右 −3 dB 交点均在公共窗口内部；
- 两批对同一组合均满足闭合条件。

另外显式保存 `scan_fmin_Hz`、`scan_fmax_Hz`，使扫描范围成为数据版本的一部分。把上界当协变量不能修复“峰被截断”，因此不能代替公共窗口和闭合筛选。

## 5. 物理与身份问题

### 5.1 异常组合 `(x=0.2,N1=1,N2=7)`

现有局部趋势分析适合**定位**，但不足以判定 A 或 C 谁正确。使用 C 邻居趋势去评价两批存在不对称性，不能作为最终仲裁。

正式处置：

1. 不删除数据，状态改为 `quarantined_pending_rerun`；
2. 主统计暂不纳入；同时必须给出“包含该点”的敏感性版本，避免选择性报告；
3. 从原始 `.mph` 直接核对该组合的解索引、参数值和复声压实部/虚部；
4. 在模型副本中只重跑该组合，重点 5–12 MHz，并保留相同材料、边界、电极、网格和求解器设置；
5. 若重跑支持 A 或 C，只追加更正记录，绝不覆盖原镜像。

建议自动隔离规则预注册为：

- 批间同点 `|ΔSPL| > max(0.5 dB, 10×正常重合点 p99)`；
- 且连续不少于 3 个共享频点超阈值；
- 且批内局部稳健残差 `|z_MAD| > 8`。

三项同时满足才自动隔离。只有两个批次时只能判断“不一致”，不能自动认定哪一批错误；三批以上才可用跨批中位数/MAD 仲裁。

### 5.2 PMUT 的最低可接受 L1

采用 3 级网格：coarse / medium / fine，相邻网格最大单元尺寸比建议约 1.3；几何、材料、求解器和频率采样保持完全相同。

最低执行集为 **3 个哨兵设计 × 3 个网格 = 9 个求解任务**：

1. 参数空间中部的普通设计；
2. x≈0.20–0.26 的非线性热点设计；
3. 第一辐射峰位于目标附近且带宽闭合的设计。

每个设计比较：

| 量 | medium→fine 建议门槛 |
|---|---|
| 第一机械/辐射特征频率 | ≤0.5% |
| 20 MHz SPL | ≤0.5 dB |
| 中心位移、中心速度、面平均速度 | ≤2% |
| 峰值、带宽、Q（仅在峰闭合时） | ≤5% |

同时记录自由度、单元数、最小网格质量和求解状态。能计算时报告 Richardson/GCI；不能稳定估计阶次时，不伪造 GCI，只使用 medium→fine 差并说明限制。

在 L1 完成前，代理模型相对误差仍可用于回答：

> “代理模型能否复现这一套固定离散规则产生的 COMSOL 数据？”

但不能回答：

> “真实器件的绝对声压、带宽或灵敏度是多少？”

### 5.3 `fmax` 是否改变网格

6039 个共享点高度复现，是非常强的“共享频点输出一致”证据，但不能替代网格身份检查。它不能排除：

- 两个模型都使用了不同但已充分收敛的网格；
- 网格序列未重建；
- `lamda/hmax` 被其他上下限钳制；
- 只有部分域受到 `fmax` 影响。

正式关闭该问题必须增加 `mesh_fingerprint`：

- `fmax`、`lamda`、各域实际 `hmax`；
- 网格特征节点及设置；
- 总单元数、各维单元数、节点数、自由度；
- 最小/平均网格质量；
- COMSOL 版本、mesh build 时间或网格序列哈希。

结论应改成：“两批在共享输出上等价；网格是否相同仍待 fingerprint 证明。”

### 5.4 `Vave` / `Vcenter`

继续判为不可跨 A/C 与 B 合并是正确的。

A/C 侧现有导出定义可以明确为：

- 中心点位于 `(0,0,10 nm)`；
- `Vcenter` 来源于该点的 `solid.u_tZ`；
- `Vave` 来源于指定顶面上 `solid.u_tZ` 的面积积分除以面积；
- 中心位移来源于同一点的 `w`。

B 侧在拿到表达式、数据集、点/面选择和归一化原文之前，不得仅凭近似常数比例改名合并。
现有数据能做的最强检查是复数传递比：比较幅值比、相位差及其频率依赖。如果复数比在多组合、多频率上近似常数，只能说明“可能是固定归一化差异”，仍不能证明表达式同义。

### 5.5 `base_model_id`

接受长期为 NULL；不允许拿文件名或任意一个产物哈希冒充公共模板。

现阶段身份链使用：

```text
artifact_sha256
configuration_id
generator_script_sha256
solver_version
physics_signature
mesh_fingerprint
electrode_mapping_signature
```

可以新增 `model_family_signature` 表示共同建模规则，但它不能改名冒充 `base_model_id`。未来若拿到真正模板，再以追加版本填入。

## 6. 数据持续增长时的版本规则

“新 run 到达后旧结果整体作废”过严。改为不可变数据发布：

```text
C_v20260928 = N2 5/6/7
C_v20260929 = C_v20260928 + te2_8
C_vNext     = 上一版本 + te2_9 ...
```

每个版本绑定：数据清单 SHA-256、模型列表、组合集合、频率网格、异常隔离表、切分定义、随机种子和预注册版本。

规则：

1. 旧结论继续对旧快照成立，不称“作废”；
2. 新 run 先作为锁定的外部增量测试，不能先看结果再调模型；
3. 若仅评估，不需要重训，也不必重跑所有历史折；
4. 若把新 run 加入训练，必须创建新预注册和新模型版本；
5. 跨版本只比较完全相同的冻结测试集；不能直接比较各版本各自的 max。

这样既保持严谨，也避免每多一个 run 就把全部工作推倒重来。

## 7. 其余三项意见

### 7.1 `provisional_first_mode`

可以用于筛选、排名和主动选点，但必须：

- 保留 `provisional` 标签；
- 分开第一机械候选峰和第一辐射峰；
- 报告证据来源和置信等级；
- 不把它写成“已验证的一阶振型”。

正式模态身份仍需要场图、振型节点或模态参与因子验证。

### 7.2 数据 B 的合法用途

数据 B 不进入 A/C 的声学绝对值训练，但仍可用于：

- 电阻抗趋势和电极接法检查；
- 参数单调性/方向性的定性交叉检查；
- `Vave/Vcenter` 定义核对与固定比例诊断；
- 解析器、单位、列映射和回归测试；
- 发现求解失败或数量级错误。

不得用 B 补齐缺失声压，也不得与 A/C 拼成同一绝对值排名。

### 7.3 自动离群

采用“批间差异 + 批内局部残差 + 连续频点”三证据规则；异常点只隔离，不删除。任何正式报告均同时给出：

- 全量结果；
- 隔离后结果；
- 两者差异。

这样可以控制选择偏倚。
