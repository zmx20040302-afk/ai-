## 5. 参数化峰型拟合（替代网格交点法）

### 5.1 模型与拟合

对一阶峰邻域（峰左右各 4 个频点，共 9 点）拟合**单自由度谐振**的幅频响应：

```
SPL(f) = C + 20·log10( 1 / sqrt( (1 − r²)² + (r / Q)² ) ) + m·(f − f0)，   r = f / f0
参数： f0（峰频）、Q、C（常数电平）、m（局部线性倾斜）
约束： f0 ∈ [f1·0.97, f1·1.03]、Q ∈ [0.3, 200]、|m| ≤ 1e−5 dB/Hz
输出： BW = f0/Q， ζ = 1/(2Q)
```

实现：`work/runs/first-peak-20260929/fit_peak_model.py`（sha256 `0e414b039559b807`），
`scipy.optimize.curve_fit`，`maxfev=20000`。

### 5.2 拟合结果

| 项 | 值 |
|---|---|
| 拟合成功 | **1612 / 1612**（失败 0） |
| **RMSE 中位** | **0.0096 dB** |
| RMSE p90 | 0.048 dB |
| **RMSE 最大** | **0.114 dB** |
| RMSE > 0.5 dB 的组合 | **0 / 1612** |
| **Q（拟合）p10 / p50 / p90** | **2.71 / 2.95 / 3.39** |

⇒ **一阶峰在该数据里就是一条近乎标准的单自由度谐振曲线**。
拟合质量本身即为"峰是孤立的、单模主导"的**证据**（有重叠模态时 RMSE 会显著变大）。

> 对照：网格交点法给出的 Q 为 p10/p50/p90 = 2.170 / **3.128** / 3.974（`first_peak_labels.json`）。
> 两者中位相差约 6%，但**拟合值分辨率更高、且不依赖 0.5 MHz 量化**，故采用拟合值。

### 6.1 一个需要用户判断的物理事实

**一阶峰的 Q 分布极窄**（拟合值 2.71–3.39，网格值 2.17–3.97）⇒
在本设计空间内 **Q 几乎与设计无关**（低 Q、强阻尼体系）。

**影响**：若把 **Q 或 ζ 当作"性能排名"的判据，可能几乎分不出高下**（区间远大于设计带来的差异）。
可选替代判据（请用户定夺）：
* 用**带宽的绝对宽度**（`BW` 或归一化带宽 `BW/f1`）——但 `Q ≈ 常数` ⇒ `BW/f1` 也近似常数；
* 用**带内平坦度**（−3 dB 带内的 SPL 起伏）；
* 把 Q 从"排名判据"降级为"**筛选门槛**"（例如只要求 Q ∈ [2.5, 3.5] 合格），排名交给振幅/灵敏度。

## 7. 灵敏度：公式已实现，**一处待确认**

按 R5 实现（`ΔV = 2 V`）：

| 量 | 归一公式 | 说明 |
|---|---|---|
| `\|w\|`、`\|v_struct\|`、`\|p\|`、`p_RMS` | **÷ 2** | 线性幅值 |
| **SPL** | **− 20·log10(2) = −6.0206 dB** | **dB 量不能直接除以 2** |
| 声功率（线性） | ÷ 4（功率 ∝ 电压²） | 仅作约束量；**若需要请确认** |

**推导**：`SPL = 20·log10(p / p₀)`，而 `p = ΔV · p_per_V`
⇒ `SPL = 20·log10(p_per_V / p₀) + 20·log10(ΔV)`
⇒ 折算到"每 1 V"须**减去 20·log10(ΔV)**。

**待用户确认**：
* 若口径是 **dB re 20 µPa / V**（物理等价于 1 V 驱动）⇒ 本实现正确；
* 若口径是 **dB/V 数值比**（即"SPL 数值 ÷ ΔV"）⇒ 请告知，我改为 ÷2 并在产物里注明该口径非物理量。

每个产物同时给出：**原始值、ΔV、归一后值、所用公式**（便于事后审计与口径切换）。

## 9. 下一轮实现方案：多通道 + 一阶峰判据的代理

### 9.1 架构（关键设计决定：判据由预测频谱**导出**，保证自洽）

```
输入 (x_scale, N1, N2)
   │
   ├─ 多通道频谱预测：SPL、|p|(实/虚)、|w|(实/虚)、结构速度(实/虚)、[约束通道]
   │    引擎 = 层内沿 x 的 PCHIP ＋ 同 (N1,x) 沿 N2 的一步线性外推（架构不变、输出无关）
   │
   ├─ 一阶峰判据 **由预测频谱经同一提取器导出**（与真实标签用同一套代码）
   │    → f1、SPL1、|w|1、|v|1、|p|1、f_lo、f_hi、BW、Q、ζ、灵敏度(÷ΔV)
   │    ★ 这样保证"预测的谱"与"预测的判据"**互相一致**，不会出现
   │      "BW 与谱形状矛盾"这类不自洽
   │
   └─ 保形校准（S5）：**两层都校准**
        ① 通道级：折外误差 → 逐维/同时区间（沿用现有做法）
        ② 判据级：把「预测谱导出的判据」与「真值判据」配对 → 对判据本身给认证区间
```

**为什么判据级也要单独校准**：`f1`、`Q` 对谱的局部形状**非线性**敏感
（谱上一个 0.1 dB 的扰动可能改变 −3 dB 交点位置），
所以"通道误差 ≤ 0.05 dB"**不能**直接推出"Q 的误差可忽略"。必须实测判据级误差。

### 9.2 输出与拒答

* 每个判据都给 **点估计 + 保形区间**；`α ∈ {0.10, 0.05, 0.01}`（沿用现有已校准档位，**不插值**）；
* **拒答域**（沿用并新增）：`x ∉ [0.21,0.99]`、该层无该 N1、`N2 > 最大已拟合 + 1`、
  隔离角点、**以及"预测谱上找不到一阶峰"**（对应真实的 170 个无峰组合）；
* **拒答即回退 COMSOL**，拒答域内**不给任何数字**。

### 9.3 前端（已就绪的网页控制台上扩展）

新增「**一阶峰**」面板：`f1`、`SPL1`、`|w|1`、`|v|1`、`|p|1`、`f_lo`/`f_hi`、`BW`、`Q`、`ζ`、
以及 `÷ΔV` 后的灵敏度，**每项都显示认证区间**；频谱图加通道选择；
「约束」区单列功率/应力/能量（**明确标注不参与排名**）。
（控制台现状见 `docs/WEB_SERVICES.md`；`http://127.0.0.1:8877/`，默认离线模式。）

### 9.4 红线（不变）

* **无场数据 ⇒ S1 场级误差界不可测** ⇒ 不得称"AI 求解器/免 COMSOL 出解"；
* **无 L1 网格收敛** ⇒ 不给工程绝对值，只谈趋势；
* 状态只能是 `draft_surrogate`，**放行权在人**；
* 预测值**不得**与 `simulation` 混列统计；入库需 `model_id` + `uncertainty`。
