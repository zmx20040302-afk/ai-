### 1.2 EDA6.4（模拟设计自动化的 AI/ML）——**可完成，但要重新定位**

**已有**：`n3_dse/N3_DSE_REPORT.md` —— 105 次注册调用、失败率 2/100、目标 `P_rad20_per_V2` 跨 574 倍；
四臂固定预算结果：`A1_random`（**5 种子**）简单遗憾 18.78 %、`A2_greedy`（1 种子）14.85 %、
`A3_gp_ei`（1 种子）**0.00 %**、`A4_gp_ei_gated`（1 种子）**2.46 %**；
`A3/A4` 的 best@k5 落在 A1 五种子分布的**分位 1.00**；**24/25 = 96 %** 的无门禁 EI 提议落在语料覆盖域外。

**缺口**

| 缺口 | 是否需要新求解 | 估计成本 | 说明 |
|---|---|---|---|
| A2/A3/A4 **多种子**（各 +4） | ✅ | 3 臂 × 4 种子 × ~30 min ≈ **6–7 h** | 直接决定「算法是否稳定优于基线」这一问 |
| **coverage–regret 曲线**（把「2.46 pp 遗憾换 96 % 少问无效点」画出来） | ❌ | 分钟级 | **这是把弱点变成卖点的关键** |
| **约束闭环任务**（带宽闭合 / Q 区间 / 峰身份） | ⚠️ 部分零求解：N4 语料已有 **25 频点 × 30 设计点**，可**离线**算出带宽/Q/峰身份作 oracle 表；但**交互式**闭环仍需 oracle | 离线分析数小时；真闭环需新求解 | 若只做「后验分析」则零求解，但说服力弱于真闭环 |
| 与 **constrained BO / safe BO / failure-aware BO** 对比 | 大概率 ❌（可在既有 oracle 表上跑） | 数小时–1 天 | 审稿人必问 |
| 第二器件 / 第二 FOM 验证 | ✅ | 天级 | 单器件是主要软肋 |
| **算法新颖性** | — | 写作 + 定位 | 外部评估说得对：目前是**工程组合** |

**诚实的定位**：不要写成「新的 BO 算法」，而写成
**「abstention-aware / failure-aware 的可靠性–效率权衡」**：用一个**可测**的代价（遗憾 +2.46 pp）换**可测**的收益（无支持查询 −96 %），
外加多组子统计。这个主张**已经被数据支持**，且 AI1.1/EDA6.4 都能接纳；但要过 EDA6.4 的「方法新颖性」门槛仍需约束任务或第二器件。

### 1.3 EDA6.5（模型降阶）——**本轮不建议**

**核心结果是硬失败，且三类补救全部已在仓库里试过**（25 频点语料，关键区 max，阈 2 %）：

| 表示 | n1_4 交叉格 max | n1_7 交叉格 max | 训练自控（中位） | 判 |
|---|---:|---:|---:|---|
| `linear`（注册口径） | **36.34 %** | **42.89 %** | 0.03 % / 0.01 % | ✗ |
| `cubic` | **26.47 %** | **50.11 %** | 0.03 % / 0.01 % | ✗ |
| `vector_fitting_common_poles` | **84,516 %** | **101,475 %** | 1.14 % / 1.96 % | ✗（爆掉 3 个数量级） |
| `phase_explicit` | 115.95 % | 162.16 % | **103.28 % / 101.94 %（训练上都失败）** | ✗ |
| `operator_mlp` | 255.43 % | 842.11 % | **291.60 % / 247.75 %（训练上都失败）** | ✗ |

**没有任何一类在任一族上通过**（`per_variant_families_passing` 五个键全为 `[]`）。
再加上此前两条独立否证：**k=4 → k=120** 自重构 → 0.000 % 而交叉格不变（非基截断）；**预注册 stage-3「只改频率轴」**后最好 `cubic` 仍 **26.46 %**（非采样密度）。
⇒ 要投 EDA6.5，需要的是一个**在这些都失败之后仍然有效的新方法**，而且还要补
**稳定性/因果性/无源性、端口宏模型、SPICE/状态空间接口、加速比与 break-even** —— 现有件里**一个都没有**。
**这是研究项目，不是 4 周修稿。**
