## 3. 最短可行路径（若目标是「至少一个任务在零 COMSOL 调用下完成求解」）

按 §6.4 与 P4.5 的 M1，**必须**同时满足：S3 通过 + 独立场级留出上 S1/S2 达标 + S5 达标 + 一个任务零调用完成并经抽查落在误差界内。

**最短序列（依赖关系严格）**：

```
A2（裁定能量项怎么收）──┬─▶ A1（×0.5 细化档复测）──▶ A3（并入权威件）
                        │
B1（选定 FOM）──────────┴─▶ B2（补 (x,f) 采样）──▶ B3（谐振参数化 ROM）
                                                     └─▶ B4（场级跨族留出）─▶ B5（多频 S5）
                                                                              └─▶ C1→C2→C3（冻结+注册+盖章）
                                                                                    └─▶ 第一个零调用求解 + 抽查
```

- **乐观估计**：若 A2 选「口径可收（不改模型）」，则 **A3(0.5 天) + B(8–12 天) + C(3–4 天) ≈ 2–3 周**（机时：服务器 ~70–90 h 串行）。
- **悲观估计**：若 A2 选「改模型（闭合电路）」⇒ 新 sha ⇒ S0–S5 **全部重走**，且 N3/N4/标签链的载体一致性要重判 ⇒ **+2–4 周**，且与论文已冻结的载体表述冲突（需 append-only 更正）。
- **A1 之后"加密"这条捷径已被排除**：缺口外推极限 ≈ −3.78 %，离 0.5 % 阈值差 ~8 倍，继续加密只会消耗机时。
- **最小化替代**（**不是** certified solver）：把现状明确定位为**筛选器/调度层**——这正是当前英文稿的措辞，且已被 N3 的闭环结果支持（GP-EI 在 5 次调用后超过全部 5 个随机种子；96% 未门控提议落在证据域外）。

## 4. 现在**不能**宣称什么（红线 7/8）

- 不能宣称「免 COMSOL 出解」或「已验证等价于 COMSOL」（`solver_spec.state=draft`、`model_id` 空、S3 失败）；
- 不能给**工程绝对值**（L1 严格口径未过 + S4 事后口径 + 能量不闭合）；
- 不能把**标量代理**当作场级求解器（它只有一阶峰标量，无场级误差界）；
- 不能把**端口 ROM**（3 极点 Foster 拟合，残差 8–10%）当作已验证的端口模型；
- 不能在**已声明适用范围之外**给任何数（拒答 + 回退 COMSOL 已在 P4 端到端实测通过）。

## 5. 一句话总结

**距离 AI 求解器，差的第一件事不是模型，而是一条裁定**：能量闭合项（S3 两项失败之一，另一项已证明是口径作废）要怎么收。
这条定了，后面是**确定性的工程序列**：补 (x,f) 采样 → 谐振参数化 ROM → 场级跨族留出 → 多频 S5 → 冻结 ROM + 注册 + 盖章；
按现有机时约 **2–3 周**（乐观）/ **4–7 周**（若改模型）。在此之前，平台的正确定位是**筛选器与高保真调度层**。

**建议的下一步（零新求解，需新预注册）**：**关键区加权 POD（W-POD）** —— SVD 前按关键区加权，

那时才需要"10 倍采样"或"算子学习（FNO/DeepONet）"这类周级投入。
