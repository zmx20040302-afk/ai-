## 0. 为什么是这一件（一个动作松动三个卡点）

| 卡点 | 现在的状态 | 有了场快照之后 |
|---|---|---|
| **S1** 场级相对 L2 | 不可测（无场） | **可测**，阈值：关键区 < 2%、全域 ≤ 5% |

### 决策 ② 取哪个场？

| 候选 | 物理含义 | 我的建议 |
|---|---|---|
| **声压 `p`（水域名）** | PMUT 的工程输出（辐射/指向性/轴向声压） | **主目标**。顺带补上此前被认定为"真正的判据但未实现"的 **7R 轴向声压 `H_p(f)`** |
| 结构位移 `u`（固体域） | 膜面振动形态 | 次目标（可选，与 `p` 相关性高） |
| 电势 `V` | 电场分布 | 可选；若只为 S1 可不做 |

> **⚠️ 7R 可能根本不在模型里（Phase 0 必须先查）**：`R_mem = N_mem × W_min = 10 × 4.2 = 42 µm`，
> 7R ≈ **294 µm**；而模型里的水域是 `sph1` 半径 **150 µm**。**294 > 150 ⇒ 7R 轴向点在水域之外**。
> ⇒ 要么水域半径不够（需要改模型/换判据位置），要么 7R 判据在本模型上不可实现。**这件事必须先在 Phase 0 查清并报你**，
> 不能等跑完几十次求解才发现。

### 决策 ③ 规模：多少个快照、留出怎么切？

- 技能 `field-io-contract` / `ai-solver-verification` 建议 **POD 用 30–60 个场快照**。

  或**整族留出**，并在报告里标注 `valid_cross_family_ood` 判定结果。

  再决定要不要扩展频点。

## 2. 分阶段执行计划

### Phase 0（先做，基本不烧机时）——把"能不能做、要多少钱"钉死

1. **只读探查基座模型的几何水域范围**：实测 `sph1`/`par1` 之后水域的实际 `r`/`z` 范围（用平台的几何测量路径，
   注意 `AGENTS.md` §4 关于「测量 API 必须查到接口层」的教训），回答 **决策 ② 的 7R 问题**。
2. **读回模型里可用的场表达式与频率列表**（运行时回读，不用 `.m`——`.m` 会被末尾赋值覆盖，本轮已两次踩到）。
3. **定义公共点集**（`field-io-contract` §1/§4）：按水域实际范围给 `(r,z)` 规则网格 + 显式坐标文件；
   给出点数与理由；**冻结点集规格**（写进 `device_spec.public_point_set`）。
4. **写场导出器**，只用**已实测可行**的路线：
   ```
   evaluate("x")/("y")/("z") + evaluate(<场>) → scipy.griddata → 固定公共点集
   ```
   **禁止**再试三条已否掉的路（`Grid` 数据集 + Eval / `Interp` 数据集 / `Export(location=grid)`）。
5. **实测单快照成本**：跑 **1 次**求解 + 场导出 + 插值，记录：求解耗时、导出+插值耗时、
   峰值 WS、avail/commit 最低值。**这就是 Phase 1 的单价依据。**
6. **冻结导出器**：按 `freeze-and-acceptance` 的纪律对导出器做**可执行哈希锁**
   （否则 S1 的数字不可复核），并把点集规格一起锁定。
7. **出手**：`Phase 0 报告 + 成本表 + 3 个决策的待签项` ⇒ **停下来等用户签字**。

### Phase 1（签字后）——训练快照

- 按用户批准的规模，逐组合求解+导出；**串行、一次一个 COMSOL 实例**；
- 每个快照落 `work/exports/*.npz` + 元数据（`run_id`、参数、频点、抽取器 sha256、点集 sha256、单位 SI）；
- 域外 NaN **不填 0**；公共掩膜在 Phase 3 统一算；
- 每个快照跑 **S3 检查**（`scripts/check_s3.py`），不通过的快照**作废、不入训练集、如实登记**。

### Phase 2（签字后）——独立留出快照

- 按"整列 x_scale / 整族"留出，**另外**求解留出快照（不与训练共用任何组合）；
- 留出集在生成阶段就与训练集物理隔离（不同目录、不同 run_id）。

### Phase 3 —— S1/S3/S5 评估

- POD/ROM：`memsharness.pod.fit_pod` → 基系数回归（技能建议默认岭回归）→ 场 = 均值 + Σaᵢφᵢ；
- **S1**：`rel_L2 = ‖pred−true‖₂/‖true‖₂`，**只在掩膜上、逐留出快照、报 max**（不看均值）；
  阈值 关键区 < 2% / 全域 ≤ 5%（阈值**原样取自技能**，一个不改）；
- **S3**：对**真实场**与**预测场**分别跑守恒/边界/对称/极限；任一 False ⇒ 该场解作废；
- **S5**：场级留出下重做保形校准（`pod.conformal_quantile`，≥9 点），报实测覆盖率与半宽；
- 结论照旧如实：`solver_certified` / `model_state` / `approved_for_use` 三项**不得**为了好看而抬。

### Phase 4 —— 报告与放行请求
