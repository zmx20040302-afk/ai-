# 报告与证据规范

本技能把 `AGENTS.md` 红线 1、2、5 与 `WORKING_PLAN.md` 第 6、10 节落成可执行的写作规则。
**目标：任何一个进入报告的数字，都能被第三方顺着溯源 ID 走完全程。**

## 0. 两条不可协商的规则

1. **没有证据就不出数字。** 报告里的每个数值必须能追溯到 `run_id`（仿真）、`evidence_id`（文献，含页码与
   原文摘录）、`experiment_id`（实验）或 `feedback_id`（人反馈）。工具没返回的数值，禁止凭记忆或推测填写。
2. **没有摘录就不算证据。** 文献数值必须带**原文摘录**与**页码定位**；只给「某文献报道了 X」而没有引文与
   页码的，一律不算证据，不得据此出数。

## 1. 数值级溯源：每个数字都要挂 ID

报告中的每个数值（表格单元格、正文数字、图注里的数、结论里的数）都必须标注来源 ID。推荐格式：

```
谐振频率 20.4 MHz  [run_id=RUN-2026-0612-0007]
灵敏度 1.85 µm/V      [run_id=RUN-2026-0612-0007, sample_id=S-000123]
压电常数 d31 = -190 pm/V [evidence_id=EV-0031, p.12]
实测灵敏度 1.9 µm/V   [experiment_id=EXP-0004，不确定度 ±0.1]
建议激励电压上限 4.5 V [feedback_id=FB-0011，评审意见]
```

规则：

- 溯源 ID 必须指向平台内**真实存在**的记录（可用 `mcp__mems__run_trace` 按 `run_id` 追溯运行 + 样本 + 产物）。
- 表格建议**单独一列** `来源`，逐行填写；不要把溯源集中写在表注里一句「以上数据来自仿真」。
- 图（曲线、云图、对比图）必须在其数据文件与图注中都带溯源；图注写出来源 ID 与保真度等级。
- 由多个数值计算得到的派生量（比值、效率、差值）也必须标注：写出用的输入值及其来源 ID，
  并说明计算方式；派生量的不确定度按传播规则给出（至少在无法严格传播时给出保守估计）。
- 同一句话里混用了不同来源，必须逐项标注，**不得用一个统一的来源概括**。
- **禁止**出现的来源写法：`[来自仿真]`、`[参考文献]`、`[内部数据]`、`[经验值]`、`[待补充]`（除非该数值本身
  被明确标注为不可用于工程判断）。
- 无法溯源的数值：**删除它**，或改写为明确的缺口陈述（见第 5 节）。不得保留为无来源数字。

## 2. 文献证据：原文摘录 + 页码定位

`evidence` 表的契约（`store.py`）：`quote` 为 `NOT NULL` —— **没有原文摘录的记录根本建不成证据**。

每条文献证据必须包含：

| 字段 | 要求 |
|---|---|
| `citation` | 完整引文：作者、标题、期刊/会议、年份、DOI 或出版社链接 |
| `locator` | 定位：页码（必填）；有公式/表格就给公式号或表号；有行号更好 |
| `quote` | **原文摘录**（逐字引用，保留原语言与单位），不得改写、不得翻译后当作原文 |
| `claim` | 本条摘录支持的结论（一句话，可用中文） |
| `confidence` | 置信标注（见第 3 节证据等级） |

写作规范：

- 摘录必须能让读者在原文献中**直接定位**：写明页码（必要时到节/公式/表号），例如
  「Kim et al. 2021, *J. Microelectromech. Syst.* 30(4), p.512, Table II」。
- 数值必须连**原文单位一起摘录**，再另行给出 SI 换算；换算过程与假设（如取 ρ、c 的文献值）要写明。
- 文献值默认标记为「文献级证据」。只有**多源一致**或**被仿真/实验复现**后才可升级为训练标签，
  且升级动作要在报告中说明依据。
- 无法获得原文（仅有摘要、二手引用、二手综述转述）时：**明确说明**「仅有摘要/二手引用，未取得原文页码与摘录」，
  该数值不作为证据使用。
- 禁止：凭模型记忆写文献数值；把综述的转述当原文；编造页码、公式号或作者年份。

## 3. 每条结论必须标注证据等级与不确定度

证据等级沿用平台验证等级（`validation` 表，`level` 为 L0–L5）：

| 等级 | 内容 | 通过标准（示例） |
|---|---|---|
| L0 | 解析基准（对闭式解/极限情况） | 关键量相对误差 < 1%（1D）、< 3%（2D） |
| L1 | 网格收敛（3 组网格 + Richardson 外推） | 相邻加密差异 < 1% |
| L2 | 守恒/能量/对称性 | 残差在容差内 |
| L3 | 交叉模型（2D vs 3D、降阶 vs 全阶） | 偏差可解释且 < 阈值 |
| L4 | 仿真留出集（未参与训练的点） | 相对误差 < 用户设定阈值（默认 3%） |
| L5 | 实验对标（实测 vs 预测） | 落在预测区间内；否则触发校准 |

每条结论的标注格式（缺一不可）：

```
结论：将压电层厚度从 2.0 µm 增至 2.4 µm，谐振频率下降约 6%（趋势）。
证据等级：L1 已过（相邻网格差异 0.4%）；L4 未评估（无同族留出点）。
不确定度：谐振频率 ±2.1%（网格离散 ±0.4%，材料常数 ±1.5%，工艺厚度公差 ±1.4%）。
适用范围：t_piezo ∈ [1.6, 2.8] µm，方形膜，无残余应力梯度。
```

要求：

- **证据等级**：写清过了哪几级、哪几级未做。不得写「已验证」而不说明验的是什么。
- **不确定度**：给出数值或区间，并列出主要来源分量；无法量化时说明原因，不得省略。
- **适用范围**：给出变量上下界与几何族；代理模型结论还要给模型 ID + 版本 + OOD 标记 + 是否通过门禁。
- **证据等级与措辞强度必须匹配**：L0–L3 通过只支持「模型自洽」类结论；要支持工程决策需要 L4；
  要对标真值需要 L5。
- **人保留放行权**：智能体不得自行晋升模型状态，也不得把「待验证」描述为「已验证」。

## 4. 未过留出集阈值的模型：只谈趋势，不给绝对值

- 未通过 L4 留出集阈值（默认相对误差 3%）的模型：**只允许比较趋势**（A 比 B 大/小、单调性、排序），
  **禁止输出用于工程判断的绝对值**。
- 明确写法：「模型未通过留出集阈值（当前相对误差 7.4% > 3%），因此本报告只给出**趋势**：增大厚度使频率下降。
  该趋势不得用于确定具体频率数值。」
- 禁止把「趋势可信」偷换成「数值可用」：不要写「约等于」「大致为」「参考值」来夹带绝对值。
- 禁止只报平均误差掩盖分量误差：误差按输出分量分别报告（相对 RMSE / MAE / R²），不做平均掩盖。
- 不确定度区间必须报**校准结果**（如 90% 区间覆盖率与区间宽度）；覆盖率不在 85–95% 时说明区间不可直接使用。
- OOD（超范围）请求必须**拒答**而非外推给数：写明「该输入落在模型适用范围之外，已拒绝出数」。
- 文献/人反馈来源的数值，其证据等级与仿真不同，不得用同一句话合并成「综合结果」。

## 5. 正确表达「需要补什么」，不要含糊其辞

门禁或验证不通过时的固定动作：**不输出数值，只输出「需要补什么数据 / 做什么实验」**，并且要具体到可执行。

要求每一条补齐需求包含五要素：**缺什么 → 为什么缺 → 补了能解锁什么结论 → 怎么补 → 阻塞成本**。

推荐写法：

```
当前不能给出的结论：候选 B 的绝对谐振频率。
缺口：几何族 GF-square-3 在留出集中没有任何 COMSOL F3 点，因此 L4 无法评估。
补什么：该族 6 个 F3 点（t_piezo ∈ {2.0, 2.2, 2.4} µm × 边长 ∈ {180, 220} µm）。
为什么这 6 个点：覆盖当前候选 B 所在参数区域，且与训练集族不重叠。
怎么做：提交 6 个 comsolbatch 任务（单实例串行，预计 2D 轴对称每点约 15 min）。
解锁什么：解锁 L4 阈值判定；通过后本报告可给出绝对值。
若不做：本报告仅保留趋势结论，候选排序不变但无置信区间。
```

禁止的含糊表述（以及原因）：

| 禁止写法 | 问题 | 改为 |
|---|---|---|
| 「数据还不够」 | 没说缺什么、缺多少 | 列出缺失的参数点与所属几何族 |
| 「需要更多实验验证」 | 没说哪种实验、测什么量 | 写明测量量、工况、点数、目标不确定度 |
| 「建议进一步研究」 | 不可执行 | 写明下一步动作、责任输入与预期产出 |
| 「结果基本合理」 | 无证据、无阈值 | 给对照基准与相对偏差数值 |
| 「精度有待提高」 | 未给阈值与当前值 | 给当前误差、目标阈值、差距 |
| 「受限于数据质量」 | 未定位到具体样本 | 给出 `sample_id` 与具体质量问题 |

## 6. 报告交付前自检清单

- [ ] 报告中每个数值都带 `run_id` / `evidence_id` / `experiment_id` / `feedback_id`。
- [ ] 表格有「来源」列；图注带来源与保真度（F0–F3）。
- [ ] 派生量给出来源与计算方式，不确定度按传播或保守估计给出。
- [ ] 每条文献数值都有 `citation` + `locator`（页码）+ `quote`（原文摘录，含原文单位）。
- [ ] 每条结论都标注了证据等级（过了哪几级、哪几级未做）、不确定度、适用范围。
- [ ] 未过 L4 阈值的模型只谈趋势，报告中没有夹带绝对值。
- [ ] 混用的来源已显式声明（哪些 `source_type`、各多少条、什么权重）。
- [ ] 代理模型结论带模型 ID + 版本 + OOD 标记 + 门禁状态；没有把「待验证」写成「已验证」。
- [ ] 无法给出的结论已按第 5 节五要素写成具体补齐需求。
- [ ] 全文没有出现无来源数字、没有出现含糊的「数据不够/进一步研究」类表述。

## 7. 审阅他人报告时的检查动作

1. 随机抽 3–5 个数值，用 `mcp__mems__run_trace`（或对应表查询）核对能否走通溯源链；走不通即为**阻断级缺陷**。
2. 抽查 2 条文献数值，回到原文核对页码与摘录是否逐字一致；不一致即为**阻断级缺陷**。
3. 检查证据等级与措辞强度是否匹配（尤其「已验证/可信/可靠」这类词）。
4. 检查是否有把未过阈值模型的结果当绝对值使用。
5. 检查缺口陈述是否可执行（五要素齐全）。
6. 审阅意见本身也要落库为 `feedback`（append-only），不得只在对话里说。

## 8. 不变式披露机器化（R12，报告侧条款）

**现象**：一轮作业的摘要写着「只改扫频范围」，实际上还**缩小了外层取值**
（笛卡尔积 81×7 → 所需几个）。读报告的人据此以为「物理与几何一律未动」，
而**外层取值缩小会改变这一批结果的可比范围**。

**要求**：凡「按不变式声明执行」的作业（典型措辞：只改 X，Y 一律未动），报告必须**逐条打印**：

```text
· 改了什么      —— 逐项，含具体取值 / 列表长度
· 没改什么      —— 逐项，须是**实测回读**得到的，而不是「我没动」这类自述
· 缩了什么/排除了什么 —— 外层取值、网格档、频点区间…及其原因
· 明确「缩外层取值 ≠ 改物理」：每个外层取值是一次**独立求解**，
  缩它改变的是**样本覆盖**，不是物理设置
```

**并且**：这段披露必须**同时**落进 run settings（机器可读），不能只出现在人读的报告正文里 ——
否则下一位复核者无法用程序确认「当时到底改了什么」。

**禁止**：用「其余设置未变」一句概括未经逐项回读的部分；把「不变式」当口号，
而不是当**可核对的清单**。

## 9. 「两批 / 两口径不得合成总分」——补一条实例

§4 已有原则「文献/人反馈来源的数值…不得用同一句话合并成综合结果」；这里补一个
**同来源、不同口径**的实例（2026-10-08 轮实测）：

- 批次 C：频率 **5–50 MHz**，2005 行，`Q∈[2.5,3.5]` 通过 **728**；
- 批次 V2：频率 **5–35 MHz**，250 组合（可用 **146**），Q 门禁 **40**；
- 两批的标签并集表 **2255 行、带 `batch` 列**，且 **Q 门禁对账逐行一致（728，双向差集 0）**
  ⇒ **口径同源，可以并列**；
- **但通过率不可读成「器件差异」**：35 MHz 上限会把峰值卡在端点（**右删失**，92/250 = 36.8%）
  并高估宽度、压低 Q（上截止点落在端点 103/250 = 41.2%）⇒ 两批通过率**不可直接比大小**。

**写作规则（硬）**：

```text
· 只要两批的**扫描范围 / 模型变体 / 变量口径**不同（如 5–35 vs 5–50 MHz、p vs p_total_Pa），
  一律按批次分列，**不给合成数、不给合成百分比、不给平均通过率**
· 删失（峰值卡在扫描端点）与截断（上截止点 = 端点）的组合
  **不得当作正常测量值**参与排名、比较或统计
· 对账（两套算法逐行一致）只证明「口径同源」，**不证明**两批可比 ⇒
  对账与可比性是**两件事**，必须分别声明
```

**相关待办（不要自行执行）**：两批有 **167 个组合重叠**，其价值是**跨管线一致性交叉检验**
（v2 用 COMSOL 自带峰值/截断点 + 删失标志，C 是另一条管线）；
在完成该检验之前，**不得**把「两批一致」当作独立佐证，也**不得**把 batch 当作防泄漏的整组切分键
（见 `docs/INDEX-records-and-rulings.md` §92）。

### 9.1 该对账已完成（2026-10-08）：结论是「只能并置」

对账已执行（`scripts/cross_pipeline_label_check.py`，**描述性、不预设通过线、不合成总分**）：

| 量 | 可比组数 | 中位相对差 | 超 5% | 最大 |
|---|---|---|---|---|
| 峰值频率 | 100 | **0.000e+00（逐位相等 69/100）** | 31/100（其中 30 组超 100%） | 3.467× |
| 带宽 | 100 | **30%** | 97/100 | 4.699× |

```text
· 峰频逐位相等 ≠ 两批可比：带宽与 Q 的系统差不来自扫描范围，而来自 **−3 dB 截断点提取方法**；

· Q∈[2.5,3.5] 决定 ranking_eligible，而 Q 有 19% 中位差 ⇒
  **同一物理组合会因出自哪条管线而进出 Q 门槛** ⇒ 任何基于 Q 门槛的排名/通过率
  **必须标注管线来源**
· 「31/100 超 5%」与「30/100 超 100%」是**两个不同的数**，引用时不得混用
  （写「31 组差 >100%」是把两个数说成了一个）
· 本对账**不构成**对任一管线的合格判定：裁定「谁对谁错」需要各自的原始频谱与提取定义原文
  ⇒ **登记为待办，不得自行下结论**
```
