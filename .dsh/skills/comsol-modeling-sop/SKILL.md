# COMSOL 建模标准作业流程（SOP）

本技能是 `D:\桌面\memsharness` 平台内做 COMSOL 建模与求解的统一作业流程。
它与 `AGENTS.md` 的红线一致；**冲突时以 `AGENTS.md` 与用户当场指令为准**。

## 1. 最高红线：不猜测模型内部

`.mph` 是专有格式。**读不到参数、物理场、研究设置时，只能如实报告「需要导出摘要或用 API 读取」，禁止根据文件名、目录名或经验惯例编造模型设置。**

具体要求：

- 只能引用**工具实际返回**的内容。没返回的物理场接口、材料参数、边界条件、网格尺寸、求解器容差，一律不得写进说明或报告。
- 允许的表述：「当前无法读取 `X.mph` 的参数/物理场设置，需要先导出模型摘要或通过 API 读取。」
- 禁止的表述：「该模型通常采用四面体网格」「按惯例这里应该是压电耦合」「根据文件名推测激励电压为 5 V」。
- 需要模型内部信息时，走正当路径获取：让 COMSOL 导出模型摘要、用 LiveLink/MPh 或 Java API 遍历模型树、或请人提供设置截图/说明；拿到之前把该项标记为**未知**。
- 若某个结论依赖未知设置，必须显式写出「该结论依赖尚未核实的设置 X」，不得默认它取某个值。

## 2. 建模顺序（固定八步，不得跳步）

按顺序推进，每一步的产物都要留下（截图、导出、日志或结构化记录）。后续步骤发现前面步骤有误，**回到该步骤修正并重做其后步骤**，不允许「先往下走，事后再补」。

1. **问题定义**：写下要回答的物理问题、目标量、期望量级与容差；明确是 2D 轴对称、2D 平面还是全 3D，以及需要单向耦合还是双向耦合。目标量不明确就不要开始建模。
2. **几何**：参数化建模（尺寸用参数而非硬编码数字）；确认单位、扫掠/挤出方向、对称面；优先用对称性降维。
3. **材料**：逐域指定材料；确认材料参数是否随频率/温度/应力变化；损耗、阻尼是否显式给出；**材料参数必须有来源**（文献带页码摘录、实验测量、或厂商数据表），来源不明就标为待定，不得凭空取值。
4. **物理场**：选择物理场接口；逐个确认「域/边界/边/点」各层级上的设置；多物理场耦合节点是否成对且方向正确。
5. **边界与选择集**：建立命名的选择集（域/边界/边/点），并把每个边界条件绑定到明确的选择集。**选择集必须在图形窗口逐个可视化核对**（见第 4 节）。
6. **网格**：先粗后细；记录网格类型（四面体/六面体/扫掠）、单元数、最小单元质量。进入参数扫描前必须先过网格收敛检查（见第 5 节）。
7. **研究与求解**：选择研究类型（稳态/特征频率/瞬态/频域）；检查求解器设置、容差、线性求解器与内存；**长求解必须异步提交**（提交拿 `run_id`，再轮询状态），**禁止**同步阻塞调用。
8. **结果验证**：抽取目标量；做第 5、6 节的网格收敛与守恒量检查；与解析解/文献/既有实测做量级对照；记录所有偏差并解释。未通过验证的结果不得作为真值入库或写入报告。

### 工程约定（来自项目执行约定，建模时必须遵守）

- **一次运行一个目录**：`work\runs\<run_id>\` 内含输入模型、命令、日志、输出、软件版本、模型哈希，使其可独立复现。
- **求解禁止并行扇出**：COMSOL 受 license 与内存约束，求解必须单实例串行。并行只用于非求解工作（解析计算、文献抽取、报告撰写）。
- **运行前检查锁**：目标 `.mph` 旁若存在 `.lock`（GUI 正在打开），先复制到 `work\` 下再操作；生产模型一律**只读引用**，不直接改动。
- **不改别人的数据**：`D:\桌面\codex\comsol1`、`D:\桌面\换能器学习`、`D:\桌面\mems论文` 均为只读输入源。

## 3. 单位一致性

单位错误是最常见且最难察觉的建模事故来源。约定：**内部一律 SI，入库保留原始单位与换算记录。**

- 几何长度默认 m（不要混用 mm/µm 输入参数）；频率 Hz；压力 Pa；密度 kg/m³；弹性常数 Pa；压电常数按 COMSOL 约定单位逐项核对。
- 参数表达统一写法：`参数名 = 数值 [单位]`，例如 `t_piezo = 2.0 [um]`。写裸数字视为未定义单位。
- 角频率与频率不要混用（`omega = 2*pi*f`）；COMSOL 的频域研究与特征频率研究输出的量纲不同，抽取时逐项确认。
- 材料库导入后**逐项检查单位**：COMSOL 内置材料库可能以非 SI 单位显示（如 GPa、g/cm³），必须显式换算或显式声明单位一致。
- 后处理导出时同样带单位；导出 CSV 的列名必须含单位，否则视为不可入库的中间产物。
- 做量级 sanity check：用解析估计（如 1D 厚度模 `f = (1/2t)√(c/ρ)`）对照仿真结果的量级；差 1–2 个数量级先怀疑单位，而不是怀疑物理。
- 入库前用 `pint` 校验量纲；量纲不一致直接拒绝，不做静默补全。

## 4. 选择集（Selection）：必须图形核对，禁止猜测

**选择集错了，边界条件就加在了错的边界上，结果会「看起来正常但物理完全错」。**

- 每个边界条件、材料指派、载荷、监视点都必须绑定到**具名选择集**，不用「边界 7」这类临时编号直接写在物理场设置里。
- **选择集只认图形窗口的实测核对**：在图形窗口中逐个高亮每个选择集，确认高亮的实体就是预期的那一个（数量、位置、朝向都对）。不得根据坐标范围、编号顺序或命名习惯推断选择集包含哪些实体。
- 几何改动后**所有选择集必须重新核对**：参数变化、布尔运算、导入新几何都可能造成选择集数量变化或静默失效（COMSOL 通常只给警告）。
- 参数扫描时，如果几何拓扑随参数变化（例如某尺寸缩小到 0 导致面消失），必须逐点位检查选择集有效性，或改用与拓扑无关的几何；这类扫描点应作为已知风险单独标记。
- 无法在图形窗口核对时（例如无人值守批处理），**如实报告「选择集未做图形核对」**，并把该结果标记为待验证，不得声称已核对。

## 5. 网格收敛检查（进入扫描的门槛）

**3 组网格 + 相邻差异 < 1% 才允许进入参数扫描。** 这条是硬门槛，不是建议。

流程：

1. 建立 3 组逐级加密的网格（例如粗/中/细，单元数大致按 2–4 倍递增），加密方式保持一致（同为全局加密或同区域局部加密）。
2. 对每组网格求解同一物理问题，抽取**全部目标量**（不是只抽一个）。
3. 计算相邻两级网格的相对差异 `|q_i - q_i-1| / |q_i|`。
4. 判据：**相邻加密差异 < 1%** 才算收敛。任一个目标量未满足，就继续加密或改网格策略（局部加密、边界层网格）。
5. 同时检查网格质量指标（最小单元质量、偏斜度、是否有负体积单元）；质量差的网格即使差异小也不可信。
6. 有条件时做 Richardson 外推，给出离散误差估计，并把该估计作为后续不确定度的一部分。
7. 记录：三组网格的单元数、质量指标、各目标量数值与相对差异。这些记录进 `work\runs\<run_id>\`，并作为验证记录（等级 L1）写入。

补充判据：局部量（峰值应力、点位移、薄层内的场梯度）比全局量收敛慢；如果目标量是局部量，网格判据要更严，或明确说明局部量只用于趋势比较。

## 6. 单手性（方向一致性）与守恒量检查

网格收敛只说明「离散误差可接受」，不说明「物理加对了」。必须再做两组独立检查。

**(a) 方向与手性一致性（单手性）**

- 几何法向：确认关键面的法向方向与预期一致（激励面/辐射面/接地面的朝向）。
- 材料方向：各向异性材料、压电材料的极化方向、局部坐标系方向必须逐域核对；纤维/晶轴方向错了结果依然「能算出来」。
- 坐标系手性：模型坐标系、几何导入坐标系、材料局部坐标系不得混用左手系/右手系；导入几何后重新确认。
- 对称性：若使用了对称边界，确认求解结果确实满足所声明的对称性；反过来，若结果破坏了所声明的对称性，必须解释原因（可能是选择集错、材料方向错或网格不对称）。
- 单向性检查：同一物理问题在几何镜像或参数对称替换下，结果应呈现预期的对称/镜像关系；不成立则说明建模存在方向性错误。

**(b) 守恒量检查**

- 通量/流量守恒：进入某区域的通量 + 内部源项 = 流出通量 + 累积项。
- 能量平衡：输入功率 = 耗散功率 + 输出功率（含辐射、热、机械损耗）。
- 电荷/电流连续性：电极上的电荷与电流守恒。
- 动量/力平衡：静态问题中的合力应平衡（有约束时扣除约束反力）。
- 判据：残差落在设定容差内（相对残差通常 < 1%，严格场合更小），残差超限必须查明原因后才能使用结果。

**方向或守恒检查不通过时：不出数，只报告检查项与残差。**

## 7. 常见失败：表现与处置

失败必须先分类再处置，分类结果写入运行记录（`run.diagnostic`）。**处置不得静默进行**：每次自动降级都要记录「做了什么改动、为什么」。

| 失败类型 | 典型表现 | 处置 |
|---|---|---|
| **不收敛** | 求解器残差停滞或振荡；报错「Nonlinear solver did not converge」「Singular matrix」「Maximum number of iterations reached」；日志中残差曲线不下降 | ① 先确认几何/边界/选择集没错（收敛问题常常是物理设置错，不是求解器问题）；② 检查是否存在刚体位移/悬浮域（缺约束）→ 补约束或使用弱约束；③ 逐步加载（ramp 激励、分段求解、连续求解器）；④ 放宽容差并记录改动（不得只放宽容差不记录）；⑤ 优化网格质量；⑥ 更初值（用稳态/线性解作为初值）；⑦ 更换求解器（直接/迭代）并记录；⑧ 仍失败则**如实记录为负样本**，不要伪造结果 |
| **内存不足** | 报错「Out of memory」「Failed to allocate」；求解进程被系统终止；机器剧烈交换 | ① 立即减少自由度：用对称性降维、2D 轴对称替代 3D、移除无关域；② 粗化网格或改用低阶单元（并记录对精度的影响）；③ 改迭代求解器 + 预条件子替代直接求解器；④ 避免一次性存储全时域/全频点解；⑤ 对大模型（GB 级 `.mph`）只用于少量关键验证点，不做批量扫描；⑥ 仍不足则改用更高内存机器或集群后端，**并说明该结果是降维/降阶的**，不得把简化模型结果当作全 3D 真值 |
| **几何错误** | 报错「Geometry could not be built」「Self-intersecting boundaries」「Zero-thickness domain」「Invalid geometry」；面/域数量与预期不符 | ① 检查参数取值是否产生退化几何（厚度→0、间隙→0）；② 修正重叠/自相交/微小缝隙（加容差或调整尺寸）；③ 修复导入几何（缝合、去除重复面、修面）；④ 布尔运算顺序与容差确认；⑤ 几何修复后**所有选择集必须重新核对**（见第 4 节）；⑥ 参数扫描时把会引发几何错误的参数区间显式排除并记录 |
| **选择集失效** | 选择集为空或实体数变化（常见警告「Selection is empty」）；边界条件实际未施加；结果与预期物理不符 | ① 回到图形窗口逐个核对（见第 4 节）；② 几何改动后重建选择集，优先用与拓扑无关的选择方式；③ 改用显式坐标框/布尔选择而非编号；④ 检查参数扫描中几何拓扑是否变化；⑤ 无法在图形窗口核对时如实报告未核对；⑥ 修复后**重跑该点全部求解**，不得复用旧结果 |

通用处置纪律：

- 任何重试都必须记录「第几次尝试、改了什么、结果如何」，历史 append-only，不覆盖旧记录。
- 重试仍失败的任务，作为**负样本**入库（带失败分类与参数点），用于后续失败预测，不得直接丢弃。
- 求解失败不等于数据为零：失败点也是数据，但必须带 `diagnostic` 分类。

- [ ] 网格收敛：3 组网格，相邻差异 < 1%（逐目标量），否则未进入扫描。
- [ ] 方向/手性一致性与守恒量检查已做，残差在容差内。
- [ ] 结果与解析解/文献量级对照过，偏差有解释。
- [ ] 求解异步提交，单实例串行；运行目录 `work\runs\<run_id>\` 材料完整（输入、命令、日志、输出、版本、模型哈希）。
- [ ] 未读到的模型内部设置，已在报告里如实标注为「未知/待导出」，**没有任何猜测的模型设置**。

## 9. 失败时的正确话术

- 读不到 `.mph` 内部 → 「当前无法读取 `<文件>` 的参数/物理场设置，需要先导出模型摘要或通过 API 读取；在拿到之前该模型的设置视为未知。」
- 未做图形核对 → 「选择集绑定已在设置树中确认，但未在图形窗口逐个核对，该结果仍待验证。」
- 网格未收敛 → 「目标量在 3 组网格间的相邻差异为 X%，未满足 < 1% 门槛，因此不进入参数扫描、也不作为真值使用。」
- 求解失败 → 「该参数点求解失败，失败分类为 `<diagnostic>`，已作为负样本入库；当前不能给出该点的目标量。」
