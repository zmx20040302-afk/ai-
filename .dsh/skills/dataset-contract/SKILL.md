# 数据集与样本契约

本技能规定「什么样的数值才允许进入平台的数据层」。它是 `AGENTS.md` 红线 1、4、6 在数据层的可执行化，
与 `src\memsharness\store.py` 的表结构一一对应。**契约不满足的样本一律拒绝入库，不做静默补全、不做默认值填充。**

元数据库：`work\store\mems.duckdb`（DuckDB）。核心表：`task`、`design`、`run`、`sample`、`artifact`、
`dataset`、`model`、`prediction`、`experiment`、`evidence`、`feedback`、`validation`。

## 1. 样本必填：inputs 与 outputs 必须同时存在

- 一条 `sample` 必须**同时**携带 `inputs` 与 `outputs`；任一为空即拒绝入库（`store.insert_sample` 会抛错：
  「样本必须同时携带 inputs 与 outputs（禁止空样本入库）」）。
- 禁止「只有输入没有输出」的占位样本进入数据集（这类记录属于待办任务，不属于样本）。
- 禁止「只有输出没有输入」的样本（不可复现，无法用于训练或校验）。
- 每个输入/输出键必须有明确含义与单位；键名用英文（英文标识符 + 中文说明），不用含糊缩写。
- 输出必须包含**全部声明的目标量**，不得只写「结果良好」这类定性描述；某一目标量确实未抽取到，
  要么不建这条样本，要么显式写 `null` 并在 `quality` 里注明缺失原因。**缺失不得用 0 代替。**

对应的 `sample` 字段：`inputs`（JSON）、`outputs`（JSON）。

## 2. 必须带 source_type（**六种**之一，不得自造）

`sample.source_type` 只能取以下六种之一：

| source_type | 含义 | 溯源链（必填） |
|---|---|---|
| `simulation` | COMSOL 仿真值 | `run_id` |
| `analytic` | 解析/闭式解或降阶模型值 | 无（但 `extractor` 必填，须含公式/代码版本） |
| `literature` | 文献值 | `evidence_id`（必须带原文摘录与页码） |
| `experiment` | 实验测量值 | `experiment_id` |
| `human_feedback` | 人反馈修正值 | `feedback_id` |
| **`ai_solver`** | **AI 求解器输出（免 COMSOL 出解）** | **`model_id`（必须挂到具体模型版本）+ `uncertainty`（误差界必填）** |

- 取值不在这六种内 → **拒绝**（`store.insert_sample` 抛错）。不得新增自定义类型、不得写 `unknown`、不得留空
  （该列是 `NOT NULL`）。
- **`ai_solver` 是独立来源，绝不与 `simulation` 混同**：AI 解的可信度取决于模型版本与适用范围判定，
  当成 COMSOL 结果使用会直接污染结论。缺 `model_id` 或 `uncertainty` 一律拒绝入库（红线 7/8）。
- **`simulation` 样本对应的 `run` 状态必须是 `succeeded`**：失败点不得当有效输出
  （构建数据集时会被排除并附原因，不是悄悄丢掉）。
- 同一物理量的不同来源样本**分条存储**，绝不合并成一条「平均值」。
- 任何统计、训练、报告都必须**显式声明混用了哪些 `source_type`**，以及各自权重。

## 2.1 数据集构建时的强制泄漏检查

用 `memsharness.dataset.build_dataset` 建数据集，它会**强制**做以下判定并写进 `dataset.report`：

- 缺 `geometry_family` 的样本一律排除（无法判定归属 = 无法防泄漏）；
- 按几何族**整族切分**，训练集与留出集的族交集必须为空；
- 族数 < 2 时**不得假装跨族留出**：报告里 `cross_family_holdout=false` + 明确降级原因，
  并附警告「指标只反映族内插值」；
- 需要声称跨族泛化的场合（如场级求解器放行）用 `require_cross_family=True`，**直接拒绝**构建；
- 来源构成（`source_counts`）与保真度构成必须进报告。

## 3. 必须标注 fidelity（保真度等级）

| 等级 | 含义 | 单点成本量级 |
|---|---|---|
| `F0` | 解析闭式解 | µs–ms |
| `F1` | 降阶模型（1D Mason/KLM 等效电路、集总参数、模态展开） | ms–s |
| `F2` | COMSOL 2D 轴对称 / 简化 3D | min–h |
| `F3` | COMSOL 全 3D / 多物理耦合 | h–天 |

- 每条样本必须写明 `fidelity`；**不得用 F2 的结果冒充 F3 真值**，也不得在报告里隐去保真度等级。
- 混用不同保真度做训练时，必须使用多保真方法（残差学习/迁移），并在数据集报告里声明各等级样本数量。
- 保真度是多保真融合的唯一依据：先训 F0/F1 → 迁移到 F2 → 用 F3 做少量校准，不得直接用 F3 从零训练。
- `analytic` 与 `simulation` 在同一 `design` 空间下都有样本时，应做**交叉一致性检查**；相对偏差超阈值 → 告警，
  不得静默入库。

## 4. 必须记录不确定度与抽取器版本

- **不确定度**：`sample.uncertainty`（JSON，按输出分量分别给出）。至少说明不确定度的来源与类型：
  - 数值离散误差（来自网格收敛/Richardson 外推）
  - 模型形式误差（降阶/简化假设）
  - 参数不确定度（材料常数、几何公差）
  - 测量不确定度（实验）
  - 文献值范围（原文给出的区间或误差棒）
  某一分量确实无法量化时，写 `null` 并注明原因；**不得用 0 表示「不确定」**。
- **抽取器版本**：`sample.extractor` 必须是「抽取器名称 + 版本」的可追溯标识（例如 `postproc_extract@0.3.1`）。
  抽取逻辑一旦改动，版本必须变；同一数据集内混合了多个抽取器版本时，必须在数据集报告里列出。
- 溯源链：`simulation` 样本必须带 `run_id`；`literature` 样本必须带 `evidence_id`；
  `experiment` 样本必须带 `experiment_id`；`human_feedback` 样本必须带 `feedback_id`。
  **缺失溯源链的样本不得入库。**
- `quality`（JSON）记录校验标记：是否通过 L0 解析基准、L1 网格收敛、L2 守恒检查、是否被标为负样本等。
  求解失败点作为**负样本**入库时必须带 `run.diagnostic` 分类，不得直接丢弃也不得当作有效输出。

## 5. 单位：全程 SI + 保留原始单位

- 内部计算与存储一律 **SI**；入库时强制 SI 规范化，**同时保留原始单位与换算记录**（`design.units` 存 JSON
  `{name: unit}`，换算记录随样本/运行留档）。
- 用 `pint` 校验量纲；量纲不一致 → 拒绝入库，不做换算猜测（例如不假设「这个 5 是 mm 还是 µm」）。
- 导出的 CSV/Parquet 列名必须含单位；无单位的列视为不可入库的中间产物。
- 禁止把频率与角频率、Hz 与 rad/s、Pa 与 GPa、m 与 µm 混为同一列。

## 6. 数据划分：按 geometry_family 分组切分（防泄漏）

**硬规则：同一几何族的扫描点不得同时出现在训练集与测试/留出集。**

- `design.geometry_family` 是分组键（group key）：几何拓扑相同、只是尺寸不同的设计点属于同一族。
- 划分必须**按族整组切分**（GroupShuffleSplit / GroupKFold 思路），不允许按行随机切分。
- 理由：同族几何的扫描点高度相关，按行随机切分会让测试集里出现「训练集见过的几乎同一个几何」，
  指标虚高、工程上失效（数据泄漏）。
- 留出集正确性检查（每次建 `dataset` 必做，结果写入 `dataset.report`）：
  1. 训练集与留出集的 `geometry_family` 交集必须为空；
  2. 同族样本的处理方式已记录（整族进同一侧，或整族被排除并说明原因）；
  3. 若目标是评估几何外推能力，留出集应包含训练集中**完全不存在的几何族**，并单独报告该子集指标。
- 外推压力测试（极端参数、族外几何）与内插指标**分开报告**，不做平均掩盖。
- `dataset` 记录：`dataset_id`、`version`（语义版本）、`purpose`（`train` | `holdout` | `calibration`）、
  `sample_ids`（JSON 数组）、`filters`（构造规则 JSON）、`report`（校验结果 JSON，含泄漏检查）。
- 数据集一旦冻结就不再原地修改；修正通过**新建版本**实现（append-only）。

## 7. 来源永不混同（红线）

- 仿真值、解析值、文献值、实验值、人反馈值在存储中带独立 `source_type` 与**独立权重**，永不混同。
- 任何统计、训练、报告都必须显式声明：用了哪些来源、各来源多少条、各自权重多少。
- 权重约定（未经人工确认时按此起点，且必须在数据集报告里写明）：实验 > 文献（多源一致或被仿真复现）
  > 仿真 > 解析/降阶 > 人反馈中的纯偏好；人反馈的**修正值**低于实验结果。
- 文献值默认标记为「文献级证据」，只有多源一致或被仿真复现后才可升级为训练标签。
- 禁止：用文献值填补仿真缺口后当作仿真值输出；把解析值与仿真值放进同一列而不加标记；
  用「综合值」这类不声明来源的表述覆盖多种来源。

## 8. 入库前自检清单

- [ ] `inputs` 与 `outputs` 同时非空，目标量齐全（缺失显式写 `null` 并注明原因）。
- [ ] `source_type` 是五种之一，未自造、未留空。
- [ ] `fidelity` 已标注（F0/F1/F2/F3），且与实际求解级别一致。
- [ ] `uncertainty` 已记录（按输出分量；含来源与类型）。
- [ ] `extractor` 含名称与版本。
- [ ] 溯源 ID 齐全（`run_id` / `evidence_id` / `experiment_id` / `feedback_id` 按来源类型对应）。
- [ ] 单位已规范化为 SI，原始单位与换算记录已保留，`pint` 量纲校验通过。
- [ ] `design.geometry_family` 已填写（缺失就无法做防泄漏切分）。
- [ ] 数据集划分按族整组切分，泄漏检查结果已写入 `dataset.report`。
- [ ] 混用的来源已在数据集报告中显式声明（含条数与权重）。
- [ ] 未覆盖既有记录；本次修正以新增记录实现。

## 9. 不满足契约时的正确话术

- 「该数值缺少 `run_id`，无法回溯到具体运行，因此不能入库、也不能写进报告。」
- 「该文献值尚未取得原文摘录与页码定位，按契约不作为 `literature` 样本入库。」
- 「该批样本的 `geometry_family` 未标注，无法保证按族切分，暂不构建数据集。」
- 「本次训练混用了 `simulation` 与 `analytic` 两来源（权重 1.0 / 0.3），所有指标均基于该混合，不能解读为纯仿真精度。」
- 「该点求解失败并已作为负样本入库（诊断分类 `<diagnostic>`），因此该参数点没有可用输出值。」

## 10. 取值逐位复现：精确取值台账（R5，2026-10-08 轮）

**现象（实测）**：生产网格里 `x_scale=0.24` 存的其实是 **0.24000000000000002**（差 1 ulp）；
按字面 `0.24` 传参与生产值求解结果差 **0.009 dB**；而 `sprintf('%.10g')` **又把 1 ulp 截掉**，
等于「复现」时静默改掉了一个生产参数。

**要求**：

- 为每个生产批次建**精确取值台账**（母版 `work/runs/stage1-20261008/production_param_grid.json`），
  登记逐参数的**可往返十进制表示**；
- 传参一律用 **`%.17g`**（double 可往返），**不得用 `%.10g`**；
- 把「与生产值一致」做成**回归门禁**：任何「改扫频/改采样后重跑」都必须先建**回归靶**
  （母版 `work/runs/stage1-20261008/frozen_reference_5MHz.json`）；本例阈值 **1e-3 dB**，
  超阈即 fail-closed；
- 台账与回归靶都**带 sha256** 落进 run 目录，使「复现的是同一批取值」可被第三方复核；
- **组合身份键比较必须先做 ulp 归一化**（对 `x_scale` 这类浮点参数取 `round(x, 6)` 后再判等），
  否则同一组合会被判成两个组合。这不是理论风险：2026-10-08 数据侧实测因此把 v2 的新增数
  **从 83 误报成 117（虚高 34）** —— C 批存 `0.30000000000000004`、v2 存 `0.3`。
  详见 `docs/INDEX-records-and-rulings.md` §92。

**与 §1–§9 的关系**：本条不改变样本契约本体，只补上「**参数取值本身也是证据**」这一层。
§4 要求记录不确定度，而 1 ulp 带来的 0.009 dB 是**可消除的系统差** ——
必须消除，而不是写进不确定度里。
