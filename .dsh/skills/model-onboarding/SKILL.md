# 模型接入 SOP（八步）

入口：`python scripts/onboard_model.py --model <路径> --device <名字> --targets "<表达式>"`。
八步中第 1–5、8 步自动；第 6、7 步**必须人工确认**。

## 铁律

1. **只操作副本**：原件只读引用。所有改动发生在 `work/devices/<name>/` 下。
2. **读不到就写 null 并记原因**，不猜 `.mph` 内部结构。
3. **没有参数审计白名单，就不允许自动改参**——白名单里每个参数都必须有实测证据。

## 各步要点与坑（均为实测所得）

| 步 | 做法 | 坑 |
|---|---|---|
| 1 | 复制到 `work/devices/<name>/`，同名副本**按次递增**（`input.mph` → `input_2.mph`），保留接入历史 | 上次接入的副本可能仍被 mphserver 持有**文件锁**（WinError 32）→ 覆盖会失败；先 `client.clear()` 释放服务端模型再复制 |
| 2 | 用 MPh 读参数/组件/几何维度/网格/物理场/研究 | `model.evaluate()` 返回的是**数组的列表**（单表达式也是 `[array(...)]`），按标量迭代会抛 `TypeError` 并被容错逻辑吞掉 → 必须先用 numpy 展平；复数先取模 |
| 3 | **参数审计**：逐参数 ±5% 微扰，看几何是否变、选择集是否变、能否求解 | ① **必须先把基线状态归一化**（重建几何+网格再测），否则基线测的是 .mph 里保存的网格、微扰后测的是重建网格，节点数天然不同 → 材料参数会被误判成几何参数；② 数值噪声（1e-14~1e-9）不是"有效应" → 需要双阈值；③ 派生表达式（如 `c/(2*L)`）不参与自动改参 |
| 4 | **选择集完整性**：几何变后边界/域编号可能改变，物理场会**静默绑错**（求解仍"成功"但结果错） | 不通过的点按 `quality=selection_invalid` **作废、不得入库** |
| 5 | 基线求解 + 目标量探测（哪些表达式真的能求值） | 求值为空/NaN 要如实标 `unknown_no_target`，**不得冒充"无可测影响"** |
| 6 | **目标口径人工确认**（f_r 取哪种峰、k_eff² 用哪个公式、Q 定义） | 口径差异常达几个百分点，**比整个优化的收益还大**；口径变更要新建数据集版本 |
| 7 | 登记 `device_spec`（参数范围/类型/结构变体） | 本模块**不猜取值范围**，`range` 一律留 null 等用户填 |
| 8 | 公共点集与掩膜策略 | 几何变化会让公共点集里部分点落到域外 → 必须掩膜（见 `field-io-contract`） |

## 参数分类词表（审计输出）

`geometry`（影响几何）· `material_or_load`（几何不变但目标量有可测变化）· `no_measured_effect`（低于噪声阈值；**≠ 物理上无效**）· `unknown_no_target`（无可用目标量）· `selection_risk`（选择集/拓扑计数变化）· `solve_failed` · `broken`。

**白名单只收 `geometry` 与 `material_or_load`**，且必须带实测证据（几何偏移、选择集完整性、目标变化、求解耗时）。
