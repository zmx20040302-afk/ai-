# 自主寻优闭环 SOP

## 1. 人只写一次任务合同

必填：`objective`（单目标/Pareto）、`parameters`（**只允许改这里声明的量**，带单位与范围；离散工艺档位用 `type: discrete`）、`constraints`（硬约束，违反即不可行）、`budget`（点数+小时，**不可省**）、`stop`（轮次/无改进/容差）、`automation`（审批级别、`model_write: copy_only`）。

已确认的补充字段：`structure_variants`（**预先批准的结构变体清单**，范围内自主、越界请示）、`field_targets`、`public_point_set`、`target_caliber`（目标口径版本号）、`deliverables`。

## 2. 闭环时序

0. **参数与几何审计**（见 `model-onboarding`）→ 产出可安全自动改参白名单
1. **目标口径钉死**（人工确认，版本化）
2. 基线 1 点 + DOE（LHS 16–24 点）
3. 优化闭环：选点 → **单实例串行**跑 COMSOL → 抽目标量（**从谱线抽标量**，曲线本身不做优化目标）→ 更新代理 → 采集函数（单目标 EI、多目标 qEHVI → Pareto）
4. **收敛后换 2–3 套更细网格复算**，排除"网格误差造成的假最优"
5. 交付：最优/Pareto + 置信区间 + 谱线对比 + 每个数的 `run_id` + 待实验清单

## 3. 审批节奏（建议值）

批 **20–24 点/轮**；**前 2 轮逐轮批准**（确认管线与口径无误），之后「全自动 + 每轮报告卡 + 可随时叫停」。
按 200–500 点预算，批 8 会产生 25–60 次审批（过累）；批 20–24 约 10–25 次。

## 4. 轮次报告卡必含

选了哪些点、**为什么**（采集函数依据）· 已完成/预算剩余 · 当前最优 + 置信区间 · 改进曲线 · **被拒答或作废的点及原因** · 下一步建议。

## 5. 强制边界

- 全程**单实例串行**求解；求解环节**禁止并行扇出**（抢 license/内存）。`workflow` 只用于非求解环节。
- 改参只作用于 `work/runs/` 下的**模型副本**；硬预算不可省。
- **每次几何变更后必过两道硬门禁**（用户已确认为硬门禁，不通过即作废、不得降权保留）：
  1. **选择集完整性**（几何变→编号可能变→物理场静默绑错）
  2. **网格依赖假最优**（扫描期网格按特征尺寸归一化重生；收敛后换细网格复算）
- 超出已声明适用范围 → **拒答并回退 COMSOL**；拒答率是 KPI，不是缺陷。

## 6. 对标口径

误差判据必须作用在**物理量本身**（温升 ΔT、相对变化量），**不能**作用在绝对温度上：
3% × 300 K = 9 K，而整个温升可能只有 10 K —— 绝对口径下容差几乎等于放行一切（实测：边界选错的二维模型也能"通过"）。
本平台已把 `heat_slab_2d` 的判据改为 ΔT ≤ 1%；新模板同理。
